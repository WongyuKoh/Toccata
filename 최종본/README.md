# Toccata 최종본 (2026-10-06)

- 본체: L2 한 몸 뒷바, 스피커 앞판 40°
- 화면: 터치스크린 3판(Waveshare 7-DSI-TOUCH-C)
- 회로도: 개정 C

**실제로 살 금액: 580,750원** = 물건값 529,650원(53품목) + 배송비 51,100원(판매처 22곳), VAT 포함. 2026-10-07에 전원을 LiFePO4 12.8 V 배터리로 바꿨습니다(배터리와 충전기는 따로 삼). 라즈베리파이 5도 따로 마련하고, 예비는 최소로 뺐습니다(10/7). 이미 가진 부품과 공구는 빼고, 예비는 최소로 둔 금액입니다.

## 만드는 순서

1. **주문.** `01_구매목록` 엑셀 순서대로 판매처마다 주문합니다. 오래 걸리는 것부터 주문합니다.
   - 라즈베리파이 5: 납기를 먼저 문의합니다.
   - 터치스크린: 해외 구매대행이라 10/15~10/22 도착 예상입니다.
   - Norelem 인서트: 10/26 출하이고 반품할 수 없습니다.
2. **단계 0 시험.** `04_3D출력_STL/00_단계0_시험출력`을 뽑고, `05_조립·제작/03_단계0_시험_절차서.md`에 따라 시험합니다.
   - 먼저 시험 1(패드 반발)을 하고, 그다음 시험 3a(윗판 굽힘)를 합니다.
   - 결과는 `03_단계0_시험_결과표.csv`에 적습니다.
3. **본출력.** `본출력/` 96파일을 각 파일 이름의 `__N개`만큼 뽑습니다.
   - 악기 부품은 308개, 출력 공구는 4개, 기판 지그는 2개입니다. 2026-10-16부터 합판이 없습니다(A안): 남은 오꾸메 10조각(스피커 바깥 옆판·뒤판·윗판·아랫판, 가운데 아랫판·뒤판)도 출력하고, 가운데 아랫판·뒤판은 베드보다 길어 반턱 이음 3토막씩입니다. 환기 구멍·자석 자리·나사 안내 구멍이 출력에 있어 드릴로 뚫을 곳이 없습니다.
   - PETG 필라멘트는 건반 액션 약 6.55 kg(436시간), 뒷바 약 1.1 kg, 10/7에 출력으로 바꾼 판 6장 약 0.63 kg, 10/16에 출력으로 바꾼 판 10장 약 2.0 kg(49시간)이 듭니다. 가진 8 kg보다 많아 검정 PETG를 2~3 kg 더 사야 합니다.
   - 패드 바(04)는 구매한 PORON 5T용입니다.
4. **조립.** 판은 모두 출력물이고 이음은 MS 폴리머로 붙입니다(가운데 아랫판·뒤판은 반턱 3토막을 먼저 잇기). 조립 순서는 `01_CAD_출력·조립_안내.md`의 '판' 절과 조립 순서를 따릅니다.

## 이 폴더를 다시 만들 때

이 폴더는 **사본**입니다. 원본은 저장소의 작업 폴더에 있습니다: `hardware/mechanical/…`, `hardware/pcb/…`, `docs/…`.
- 설계를 바꿀 때는 원본을 고칩니다.
- 그다음 아래 명령을 실행하면 02~06 폴더를 지우고 다시 채웁니다. `--pdf`를 붙이면 도면집과 설계서 PDF도 다시 만듭니다. 이 단계에는 Google Chrome과 pandoc이 필요합니다.
  ```bash
  python3 docs/make_final.py --pdf
  ```
- 주문용 엑셀은 다음 명령으로 다시 만듭니다. 그 뒤 수식 값을 채우려면 LibreOffice로 다시 계산합니다.
  ```bash
  python3 hardware/bom/final-bom/build_order_xlsx.py
  ```

지난 설계·보고서·목록은 `archive/`에 있습니다([archive/README.md](../archive/README.md)).
