# [보관] Toccata — 1단계 하드웨어 설계 (v1.5 · 다부품 · 금속 스프링)

> **이 판은 v2.0(모노리식)으로 대체되었습니다.** 금속 인장 스프링·Ø6 힌지 핀·요람을 쓰는 다부품 구조이며, 센싱(§3)과 PCB(§4)는 v2.0에서도 그대로 유효합니다.

> 2026-09-10 · v1.0 → 1차 → v1.1 → 2차 → v1.2 → 3차(SCAD 좌표 대조) → v1.3 → 4차(기하·방향: 방향 확인) → v1.4 → **5차(CAD 실측: OpenSCAD 불리언 교차로 간섭 검사)** → **v1.5**. 이전 상용급 설계는 [archive/v0.3-overengineered.md](archive/v0.3-overengineered.md)
> **목표: 3D 프린팅 건반 + 홀 센서 + Pico + Raspberry Pi 5 소프트 신스. 예산 약 45~48만원, 파트타임 3~5개월 + 조달 2~4주.**
>
> ⚠️ **v1.3의 핵심 수정**: v1.0~v1.2의 센싱 계산은 전부 "누르면 자석이 센서에서 **멀어진다**"는 가정이었습니다. 실제 기구(피벗 y=165, 자석 y=110은 피벗 **앞**)에서는 누르면 자석이 **내려가 센서에 가까워집니다**. 그대로 만들면 건반이 센서에 부딪힙니다. §3 전체를 접근 모델로 재유도했습니다.

## 0. 한 장 요약

```
 옥타브 모듈 (도~시 12키)  ×6  +  상단 13키 (C7~C8)  +  시작 3키 (A0~B0)  = 88키
 ┌─────────────────────────────────────────────┐
 │ 프린팅 건반 12개  ─ 각 건반 밑에 자석 1개        │
 │ 프린팅 키베드 1개 ─ 열린 요람 + 인장 스프링       │
 │ PCB 1장: SS49E(눕힘) 12 + 74HC4067 먹스 + Pico   │──USB-MIDI──┐
 └─────────────────────────────────────────────┘             │
   ↑ 합판 베이스 보드 + 알루미늄 평철(피치 기준, 매립)  [셀프파워 USB 허브] ──┤
                                                               ▼
                    [Raspberry Pi 5 + 27W PSU] ─ FluidSynth ─ I2S DAC HAT ─ 스피커
```

- **모듈 하나가 곧 완결된 12키 USB-MIDI 키보드**입니다. 첫 모듈이 완성되는 순간 2단계(음원 테스트)를 시작할 수 있습니다.
- 모듈끼리 통신하지 않습니다. 각각 USB-MIDI 장치로 열거되고 FluidSynth가 자동 연결합니다. **버스·프로토콜·마스터가 없습니다.**
- 러버돔·금형·CNC·커스텀 캐리어 보드가 없습니다.

| | v0.3 (폐기) | **v1.3** |
|---|---|---|
| 센싱 | 러버돔 2접점 (금형 ₩200~350만) | **홀 센서 SS49E + 자석** (키당 ₩300) |
| 모듈 MCU | RP2354A 커스텀 + RS-485 TDMA | **Pico** (USB-MIDI 직접) |
| 연산부 | CM5 커스텀 캐리어 탈착 도크 | **Pi 5** 그대로 |
| 정렬 | 6061-T6511 CNC 레일 (₩80~150만) | 합판 베이스 + 매립 평철 + 강철자 (₩4만) |
| 건반 | MJF 외주 | **집 프린터** |
| 예산 | 600~1,100만 | **약 45~48만** |

## 2. 건반 기구 — joewing 방식 + 수정

```
 후방 정지: 키별 10×10 펠트 패드 + 펀칭       가이드 핀(fin) y=157~183, 편측 0.15
      ▼                                        │
  ════╪══◎════════════════════════════════════╪═══════════════════▶ 앞끝 (피벗에서 165)
      │  ▲ Ø6 피벗 핀 (건반 일체)               │         ▼ 누르면 내려감
      │  └ 30° 열린 요람                        │       자석 Ø3×2 @ y=110 (피벗 앞 55), 이동 3.6
   상단 앵커: y≈205 하면 Ø1.5 SUS 횡핀                  ▼ 가까워짐
```

### 2.2 88키 레벨링

후방 정지 오차가 앞끝에서 ×3.6. 키별 10×10 펠트 패드(연속 스트립 금지) + 펀칭 **0.05 · 0.1 · 0.2 · 0.5** (0.05 = 0.002" 페이퍼 펀칭 수입, 또는 0.05 황동/SUS 심·PET 필름·캡톤 테이프로 대체). 직선자로 앞끝 맞춤, 게이트 인접 단차 ≤0.3. 88키 × 2회전 × 2분 ≈ 6h. 레벨링 후 갭 공차 스택 ±0.54 → ±0.38.

## 3. 센싱 — 접근 모델 (v1.3 재유도)

```
     정지: 자석 멀리 (≈7mm) ── 출력 ≈ 널 −0.05V   ← rest = ADC 최댓값
     눌림: 자석 가까이 (≈3.5mm) ── 출력 ≈ 널 −0.28V ← 스윙 ≈285 LSB
     클램프 위험은 눌림 쪽. 공차 −0.54에서도 널 −0.40V 이내가 되도록 눌림 갭을 정함
```

| 항목 | 사양 |
|---|---|
| 센서 | SS49E, **눕혀 실장 — 브랜드면 위(자석 쪽)**. 서 있는 TO-92는 면에 수직인 자계만 감지하므로 위에서 내려오는 자석에는 거의 반응 없음. 100개 1로트 |
| **출력 부호 규칙** | **브랜드면 위 + 자석 N면 센서 쪽 → 접근 시 출력 하강** (rest = ADC 최댓값 전제). 부호는 극 × 면 방향의 곱이므로 둘 다 통일. 펌웨어는 캘리브레이션 시 부호 자동 판정 + 게이트 ②에서 '눌림 < 정지' 확인 |
| 자석 | N35 Ø3×2, N면 센서 쪽. 단계 0에서 스윙 부족 시 **Ø4×2 대안** 시험 |
| 위치 | y=110 (피벗 앞 55), 이동 **3.6mm 접근** |
| 갭 정의 | 소자 기준(눕힌 센서 상면에서 ≈0.7 아래). 심으로 조정 |
| 먹스 | CD74HC4067 (3.3V), SIG 4.7~10kΩ 풀다운, 전환 후 3~5µs 대기 |
| 센서 출력 | 채널마다 **1nF**(먹스 공통 노드 전하 공유 완화). Vcc 디커플링 100nF ×13은 별도 |

### 3.1 로트별 눌림 갭 — 헤드룸 ±0.6V, 여유 0.2V, 공차 −0.54 포함

| 로트 (3.3V 감도) | **눌림 갭 (소자)** | 정지 갭 | 눌림 출력 | 스윙 LSB 공칭 / +0.54 / −0.54 | 심 (key_elev 12.1) |
|---|---|---|---|---|---|
| Honeywell 정품 (0.92 mV/G) | **3.4 mm** (표면 ≈2.7) | 7.0 mm | 널 −0.28 V | 284 / 197 / 423 | 심 2.7 mm |
| 클론 V2 (1.19 mV/G) | **3.7 mm** (표면 ≈3.0) | 7.3 mm | 널 −0.28 V | 285 / 203 / 414 | 심 2.4 mm |
| 클론 V3 (1.65 mV/G) | **4.2 mm** (표면 ≈3.5) | 7.8 mm | 널 −0.29 V | 285 / 208 / 402 | 심 1.9 mm |

- **갭(심) = 로트 감도 상한 기준**(가장 민감한 소자가 눌림 −0.40V 이내). **기본 스윙 상수 = 로트 감도 하한 기준.** 단계 0에서 100개 전수 감도 측정(≈1h) 후 ±10% 선별해 모듈별로 묶으면 산포 항 소멸.
- 스윙 ≈285 LSB는 세 로트 모두 같음(정의상). +0.54 공차에서 ≈200 → **그때 임계 간격 A–C ≈40 / C–B ≈50**(공칭 57/71). 클램프 기준은 **§8 게이트 ③(눌림 출력 ≥1.20V = 널 −0.45V)** 하나로 통일 — 재계산 V2/V3 −0.54에서 1.24V로 통과.
- 극성은 이득 없음(헤드룸 대칭) — 통일만.
- **선택안(스윙 3배)**: 센서 Vcc = VBUS 5V(10Ω + 100µF RC 후), 먹스는 **3.3V 유지**, 채널마다 10kΩ 직렬. 헤드룸 1.45V → 눌림 갭 ≈2.5, 스윙 ≈900 LSB. 단 VBUS 리플이 출력에 실림 — 단계 0에서 리플 p-p ≤20mV 확인, 아니면 폐기.

### 3.2 벨로시티 — 두 임계값 dt + 연타 경로

```
ADC (널에서 아래로)
 rest ──────╮ 10%  A  t1 기록
             ╲ 30% C  연타 재무장
              ╲ 55% B  t2 → dt → velocity, Note On   ← 이동 79%: 실제 피아노(80~90%)에 근접
 pressed ──────╰──
```

| 임계 | 스윙 | 이동 (Honeywell 기준, 타 로트 ±2%) |
|---|---|---|
| A | 10% | 1.0 mm (27%) |
| C | 30% | 2.1 mm (57%) |
| **B** | **55%** | **2.8 mm (79%)** |

| 항목 | 값 (잠정, **하드코딩 금지**) |
|---|---|
| A→B 자석 이동 | **1.85 mm** (C→B 0.76, 보정비 **2.4**) |
| dt | fff 앞끝 0.9 m/s(자석 0.3) → **6.2 ms**, ppp 0.015 → 369 ms, 0.01 → 554 ms |
| 타임아웃 | **700 ms** |
| 로그 1스텝 | ≈200 µs → 84µs 스캔 = 0.42 스텝 ✓ |
| 노트오프 | B 역통과 |
| 릴리즈 벨로시티 | B→A dt, A 도달 시에만 |
| 히스테리시스 | **실측 스윙의 8%** (공칭 23, +0.54에서 16 LSB) — 절대값이면 +0.54 공차에서 A–C 40을 넘음 |

```
IDLE → A하향(t1) → B하향(NoteOn, dt=t2−t1) → PRESSED
A하향 후 B 미도달 재상승 → IDLE (t1 폐기)
PRESSED → B상향(NoteOff) → PARTIAL
PARTIAL → A상향 → IDLE
PARTIAL → C상향 → REARMED
REARMED → A상향 → IDLE
REARMED → C하향(t1') → B하향(NoteOn, dt' × 2.4)
```

단계 1 게이트: 10Hz 연타 100회 무유령·무누락.

### 3.3 샘플링 예산

49E 전부 소싱 전용(싱크 65µA) → 풀다운 + 3~5µs 대기. 채널 7µs → 12키 **84µs (12kHz)** → fff 1스텝 대비 0.42 스텝 ✓. SDK `adc_read()` 직접 호출. 노이즈 대책 주력: 3V3 벌크 10~47µF + 출력 1nF + 단계 0 실측. `GPIO23=HIGH`는 Pico/Pico 2만(W는 WL_GPIO1, 클론 LDO 보드 해당 없음).

**게이트 ④ 합격선: 유휴 p-p ≤ 스윙/10 ≈ 25 LSB.** 미달 시 1nF → 2탭 평균(168µs, fff 0.8스텝) → 정품 Pico 순.

### 3.4 캘리브레이션

| 항목 | **v1.3** |
|---|---|
| rest | **슬로우-맥스**: `rest = max(x, rest − 1 LSB/50ms)`, IDLE 200ms 이상일 때만. 접근 모델에서 rest = ADC 최댓값이므로 그대로 유효 |
| pressed | **최근 8스트로크 최솟값의 롤링 최소** (A를 넘어 내려갔다 A 위로 복귀한 스트로크만). 상시 상향 감쇠 **없음** — 감쇠가 있으면 20초 쉰 키의 첫 음이 +34스텝 과대 |
| 기본 스윙 | **≈160 LSB** = 로트 하한 감도 +0.54 스윙 × 0.8. 조건 `기본 < 실제/0.55`. rest ±20% 이동 시 `pressed = rest − 기본` 재유도 |
| 저장 | 상시 경로 없음. **SysEx 명령**만(버튼 없음), core1 정지 후 commit. 또는 저장 안 함(부팅 시 손 얹힘은 ≈25초 후 자가 복구) |

모듈 간: 단계 4에서 모듈별 100타 히스토그램.

### 3.5 Pico 펌웨어

core1 스캔(플래시 없음) / core0 USB-MIDI, **채널 1 고정**. 3비트 DIP → 노트 베이스(S는 고정 21). USB 제품명 동일. 설정값: 임계 10/30/55, 히스테리시스 8%, 타임아웃 700, 로그 상수, 기본 스윙 160, 연타 보정 2.4, **흑건 벨로시티 오프셋**(손가락 위치 피벗 앞 ≈95 vs 백건 165 → 같은 손가락 속도에서 dt 0.58배 → 로그 +17스텝 계통 오차 보정).

**서스테인 페달**(S 모듈): 부팅 시 '밟지 않음' 학습(+ 첫 10초 내 2회 이상 토글 시 재학습), 20ms 디바운스, 변화 시 CC64 0/127, **밟힌 동안 1초마다 127 재송**(fluidsynth 재시작·재열거 대응). 잭은 패널 마운트.

## 6. Raspberry Pi 5

### 6.1 OS: Lite + SDL kmsdrm

Desktop은 PipeWire가 HAT을 선점(`Device busy`). **OS Lite**, 게임은 `apt install python3-pygame`(시스템 SDL2, KMSDRM 포함) + `video·render·input` 그룹. **게임 오디오는 반주를 MIDI로 fluidsynth에 보내 같은 신스로 재생**(HAT `hw:` 배타 유지, 믹서 불필요, 같은 클록) — 또는 HDMI 오디오 분리. 단계 2 게이트: Pico 포트 fluidsynth 1회 구독.

### 6.2 지연 — 오디오 버퍼 기준 (키→소리 +2~3ms, RTPRIO 전제)

### 6.3 엔진·유닛

FluidSynth 2.0+ (Bookworm 2.3.1 / Trixie 2.4.4), FluidR3 시작. Pianoteq +22만 선택.

```ini
[Unit]
After=sound.target
StartLimitIntervalSec=60
StartLimitBurst=10
[Service]
ExecStart=/usr/bin/fluidsynth -is -a alsa -o audio.alsa.device=hw:CARD=sndrpihifiberry -r 48000 -z 64 -c 3 -o midi.autoconnect=1 -o synth.dynamic-sample-loading=1 /usr/share/sounds/sf2/FluidR3_GM.sf2
LimitRTPRIO=95
LimitMEMLOCK=infinity
Restart=on-failure
RestartSec=2
[Install]
WantedBy=multi-user.target
```

`-is` 없으면 systemd 아래서 셸이 EOF를 읽고 **exit 0으로 조용히 종료**(Restart=on-failure 무반응). `-s`는 TCP 9800(가정 LAN 허용). `midi.autoconnect=1`이 핫플러그·재열거 자동 연결(v2.0.0, fluid_alsa.c). 리듬게임은 ALSA seq.

### 6.4 USB 전원

모듈당 VBUS **79~116mA**(센서 12×4~7mA @3.3V + Pico 30 → ÷0.85 ÷5V), 8모듈 **0.63~0.93A**. Pi 5 USB 600mA(PD 5A 협상 시 1.6A 자동). → **셀프파워 허브(≥2A)가 1차 해법**, 27W PSU는 Pi 자체 요건. HAT은 USB 무관.

**역급전 검사**: Pi에 연결하기 **전** 허브 업스트림 A 플러그 핀1–핀4를 테스터로 측정, 허브 ON에서 **>0.5V면 역급전**(LED 소등은 증거 아님). 연결 후 40핀 헤더 5V 측정. 역급전 시 다른 허브 / VBUS 단선 케이블 / 공식 Pi USB3 허브 ×2. 전원 순서 Pi 먼저.
