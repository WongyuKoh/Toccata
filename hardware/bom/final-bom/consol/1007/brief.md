# 규칙
- 사양이 **같거나 설계상 동등**(치수·재질·핀 배치·용량·등급)해야 한다. 애매하면 spec_match에 이유를 쓰고 verified=false.
- 가격·배송비는 **실제 상품 페이지를 열어** 확인(WebFetch). 안 열리면 WebSearch 스니펫 → verified=false.
- 필요한 수량과 판매 단위(팩·최소주문)를 반영한 **총액(VAT 포함)**을 계산한다.
- 품목당 후보 최대 3개. 없으면 candidates 빈 배열 + searched에 찾아본 곳.
- 결과는 지정 JSON 파일에 쓴다. 채팅 답은 5줄 요약만.
