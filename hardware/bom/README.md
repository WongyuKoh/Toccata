LiFePO4 배터리와 충전기는 사용자가 따로 사므로 목록에 없습니다. 10/7 사용자: 라즈베리파이 5 끔(따로 마련), USB 허브 NEXTU 710U3 켬, 예비 최소화(스위치·점퍼·인서트·M3×6, −1,268원). 10/7 마지막으로 에어컨 재료 목록에서 같은 부품을 나눠 쓰기로 해(p16 인서트 세트, p17 볼트·너트·와셔 세트를 3개로, p57 연료 호스 2 m) 10품목(M3 너트, M3×10·×6·×20·×16·×5 볼트, M4 와셔, M4·M3 인서트, 실리콘 튜브)을 빼 → 587,746원. 같은 날 드릴 작업을 줄이려고 뚜껑 L·R, 가운데 끝벽 L·R, 스피커 안쪽 옆판 L·R을 출력물로 바꾸고(구멍·자석 자리를 출력으로; 합판 16 → 10조각, 드릴 구멍 약 624 → 54개), 스피커 옆판의 Norelem 나사산 인서트(4 × 1,749원)를 가진 M4 열압입 인서트로 바꿔 → 580,750원. ## 주문할 때

- 가격은 판매처 페이지에서 확인한 값(VAT 포함)입니다. 주문 전에 다시 확인합니다.
- 라즈베리파이 5(아이씨뱅큐)는 페이지에 배송기간 '8주 이상'이 적혀 있어 주문 전에 납기를 묻습니다.
- 나사산 인서트 Norelem 07653-04(나비엠알오)는 10/26 출하 주문품이라 반품이 안 됩니다.
- 터치스크린(G마켓 해외 구매대행)은 개인통관고유부호가 필요하고 10/15~10/22 도착 예상입니다.
- 굿나잇몰(11번가) 볼트·피스 상품 4개가 한 번에 묶여 배송비가 한 번만 나오는지 주문 화면에서 확인합니다.
- 메카솔루션 배송비 3,000원은 추정값입니다(페이지에 금액이 없음).
- OHP 필름은 받으면 두께 0.1 mm인지 캘리퍼스로 잽니다. 업스톱 패드는 PORON 5T를 사므로 `stl/print/04`의 5T용 패드 바를 뽑습니다.
