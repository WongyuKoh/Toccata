## 주의

- 생성 스크립트는 작업 세션의 임시 폴더에 있던 데이터를 읽습니다: 이전 절감안 데이터, 부품 사진, v3 보고서 카드. 그래서 그대로 다시 실행하려면 경로를 맞춰야 합니다.
- 가격이 "미확인"인 줄은 주문 전에 다시 확인합니다. 레이저 재단 견적, 점검 중이던 한국미스미, 로봇 확인에 막힌 알리익스프레스, 동네 철공소가 여기에 해당합니다.
- 토션 보조 스프링은 2026-09-28부터 한국미스미 경제형 기성품 C-UA90R5-3-0.5를 씁니다(100개 이상 개당 282원 + VAT, 100개 31,000원). 두 다리를 **22.3 / 8.0 mm**로 잘라 씁니다(r4.5 고침: 짧은 다리를 가둠 홈에 넣음). 구매 목록, 선택기, 부품 목록(`docs/report/toccata-parts-list.xlsx`)에 모두 반영했습니다. 직접 감기는 대안으로 남겼습니다.
- USB-C 케이블(C04)은 지금 NA993을 씁니다. 몰드 두께가 공개되지 않아 단계 0에서 꽂아 확인합니다. 세 치수가 공개돼 확인된 선은 CVILUX DH-20M50052(디지키)이고, 선택기에 대안으로 있습니다. 조사 결과는 `price-research/usb-c-cable.json`에 있습니다.
