# 건반 액션 v4 — W1+ (짧은 시소 건반 + 무게 레버)

v3의 리프 건반을 대신하는 새 건반 구조입니다. 이 폴더는 2026-09-27~29의 설계 기록입니다.
- **4차(r4.3):** 1차 완성본
- **r4.4:** 남은 문제 해결, 회로 세션 요청 반영
- **r4.5:** 비틀림 스프링을 미스미 기성품으로 교체

## 왜 바꿨나

v3는 PETG 리프 하나가 회전축과 복귀 스프링을 함께 맡았습니다. 쉬는 동안에도 약 6 MPa로 휘어 있어서, 오래 두면 처지고 건반 무게가 줄어드는 것이 1순위 위험이었습니다.

v4는 그랜드 피아노나 디지털 피아노처럼 **무게로 돌아오는** 구조입니다. 건반과 레버가 모두 금속 봉 위에서 돌고, 쉬는 자세는 펠트 위에 무게가 얹혀 정해집니다. 늘 휘어 있는 플라스틱이 없습니다.

## 구조

1. **건반:** Ø4 스테인리스 봉(y141, z21.5) 위의 짧은 시소입니다.
2. **레버:** 건반 앞을 누르면 꼬리의 M3 캡스턴 나사가 뒤쪽 무게 레버를 들어 올립니다. 레버는 출력 캐리어에 강철 블록 9×19×40(54 g)을 끼우고 **MS 폴리머 탄성 접착제로 붙인 것**입니다. Ø4 봉 위에서 돕니다.
3. **복귀:** 손을 떼면 레버 무게와 비틀림 보조 스프링이 건반을 되돌립니다.
   - 스프링은 **미스미 C-UA90R5-3-0.5**(SUS304-WPB, ID 5, 선 0.5, 3권)입니다.
   - 다리를 22.3 / 8.0 mm로 잘라 씁니다.
   - 짧은 다리는 허브의 가둠 홈에 들어가서 코일이 봉에 닿지 않습니다.
4. **맞물림:** 건반과 레버는 홈 없이 눌려 붙어 있어서 연결부에 유격이 없습니다.
5. **업스톱:** 끝까지 누르면 레버의 강철 윗면이 프레임 윗판 밑 패드에 닿아 멈춥니다. 패드는 미세셀 우레탄 6T에 펠트 1T를 겹친 것이고, 앞으로 빼낼 수 있는 패드 바 4개에 붙어 있습니다.
6. **센서:** v3와 같습니다. 건반 밑 자석 Ø5×2가 센서 줄 바로 위(y67)에 옵니다.
7. **제어 기판:** 프레임 바닥의 구멍으로 밑에서 넣습니다. 위에 매달린 보스 4개에 닿고, M3×6 2개로 밑에서 조입니다.

## 남은 일

1. **접착 강도.** MS 폴리머 접착 강도는 가정값입니다. 단계 0 시험 20에서 5 ↔ 45 °C를 3번 거친 뒤 잽니다.
2. **레일 받침.** 레일이 실제로 어떻게 받쳐지는지는 계산으로 정할 수 없습니다. 레일을 단순 지지로만 보면 337.6 N/mm로 불합격입니다. 첫 모듈 정하중 시험 21로 확인합니다. 시험은 핀 선만 받친 빗(C17a)을 깔고, 실제 하중 방향으로 합니다.
3. **스프링.** 손으로 레버를 들 때 토크가 카탈로그 55° 토크의 104 %입니다. 가둠 홈이 짧은 다리를 잡으려면 두 접점 마찰이 μ 0.10 이상이어야 합니다. 시험 8과 13에서 확인합니다.
4. **백건 앞끝 누르는 힘.** 47.1 g으로, 목표 47 g과 0.1 g 차이입니다. 모자라면 강철 앞 윗면에 퍼티를 더합니다.
5. **구매 주의.**
   - 강철 블록 두께는 8.9~9.1 mm여야 합니다. 캘리퍼로 골라 쓰거나 냉간 인발재를 삽니다.
   - 업스톱 패드 PORON은 5T가 아니라 6T로 삽니다.
6. **끝 부속 쐐기.** 얇은 끝이 A0 0.29 / C8 0.26 mm로, 출력 최소 0.3보다 얇습니다. 출력해 보고 확인합니다.

## 다시 계산하기

- **모델:** `model/`에서 `python run_all.py`를 실행합니다. numpy와 scipy가 필요하고 약 20분 걸립니다.
- **도면:** `drawings/src/`에서 `python render_v4.py`와 `python render_v4b.py`를 실행합니다. `kit.py`는 `../../model/geometry.json`을 읽습니다. PNG가 필요하면 `resvg_py`를 씁니다.
- **공구와 시편:** `printables/tools/`와 `printables/stage0/`에서 `MODEL_DIR=../../model python make_tools.py`, `MODEL_DIR=../../model python make_stage0.py`를 실행합니다. STL을 만들려면 OpenSCAD 또는 trimesh가 필요합니다.
