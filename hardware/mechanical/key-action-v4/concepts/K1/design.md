# K1 — 뒤축 건반 + 강철 압축 스프링 + 관성 추 (부품 최소 기준안)

모든 수치는 `calc.py`가 계산하고 `results.txt`에 찍은 값이다. 단위 mm, g, N, ms. 좌표는 brief와 같다(z = 0 책상면, y = 0 백건 립 앞끝, +y 뒤쪽).

## 1. 한 줄 요약과 동작

- 레버는 건반 하나뿐이다. 건반 뒤끝(y200, z33.5)이 옥타브당 1개인 **Ø5 S45C 연마봉**에 걸려 돈다.
- **강철 압축 스프링**이 프레임 바닥(z5)에서 건반 꼬리 속(y138)을 밀어 올려 건반을 되돌린다. 플라스틱은 상시 힘을 거의 받지 않는다(정지 시 최대 0.89 MPa).
- 백건 머리 속에는 **16×16×34 사각봉(68.3 g)**, 흑건 앞쪽 속에는 **6×19×47 평철(42.1 g)**을 출력 중 멈춤(pause)으로 넣어 완전히 가둔다. 이 추가 관성을 만든다.
- 스프링 예압이 건반 무게와 추 무게를 함께 들어 올리므로 누르기 시작하는 힘은 50 g이다. 추의 무게는 손끝에 느껴지지 않고 **관성만** 남는다.
- 정지 높이는 앞쪽 훅 펠트(v3와 같은 수평 훅)가 정하고, 바닥은 앞 펠트가 정한다. 연결부(커플링)가 없으므로 Casio 블로그의 "덜걱" 소리 원인이 없다.

## 3. 스프링 (피아노선 SWP-A, 양끝 닫힘·연마)

| | 백건 | 흑건 |
|---|---|---|
| 선경 × 외경 | 0.45 × 5.5 | 0.45 × 5.0 (외경이 달라 섞이지 않음) |
| 유효 권수 / 총 권수 | 40 / 42 | 75 / 77 |
| 자유장 L0 | 84.1 | 85.0 |
| 스프링 상수 | 0.0781 N/mm | 0.0570 N/mm |
| 설치 길이 정지 → 바닥 | 35.90 → 32.79 | 48.50 → 44.48 |
| 힘 정지 → 바닥 | 3.77 → 4.01 N (+6.4 %) | 2.08 → 2.31 N (+11.0 %) |
| 전단 응력 (바닥) | 638 MPa = 0.26 UTS | 335 MPa = 0.13 UTS |
| 밀착 길이 / 허용 변형 사용률 | 18.9 / 0.79 | 34.6 / 0.80 |
| 서지 주파수 | 157 Hz | 103 Hz |

- 흰·검 공용 스프링 하나는 계산으로 탈락: 흑건 시트가 z60 이상이어야 하고(흑건 윗판 밑면은 z53.5), 흑건 힘 상승이 17.2 g이 된다.
- 비틀림 스프링(축에 동축)도 계산했다: 선경 1.3이면 백건 상승 8.3 g로 압축과 비슷하고, 선경 1.2면 6.1 g로 더 평평하지만 굽힘 응력 0.79 UTS이며 코일이 건반 사이 8 mm에 들어가야 하고 건반 1개 분리가 어렵다. 그래서 압축 스프링을 택했다.
- 건반별 조정: 스프링 아래 0.5 mm 출력 와셔 1장 = 손끝 1.72 g(백) / 2.33 g(흑). 스프링 하중 공차 ±10 %면 손끝 ±12.7 g이므로 **설치 길이에서의 하중 공차를 지정해 주문**하거나 재서 나눠 쓴다.

## 6. 조립 (옥타브 하나)
1. 건반 출력: 멈춤 층에서 추를 넣고 이어서 출력(바닥 1.0이 추 위를 브리지로 덮는다). 추가 흔들리면 CA 한 방울.
2. 센서 자석(백 0.57 mm, 흑 0.23 mm 안으로 들어가게)과 포크 고정 자석을 밑면 포켓에 압입 + CA.
3. 프레임: EVA 바닥(리본 차선 x60~82, y128~146 구간은 EVA를 22 mm 폭으로 따내 리본을 바닥판 밑으로 통과), 앞 펠트(백 y3~12, 흑 y51.5~58.7), 훅 펠트 12조각, 탭 부싱 펠트 0.5T.
4. Ø5 축을 핀 콤 13장에 끼운다(양끝 핀은 억지 끼움).
5. 스프링을 가이드 기둥에 꽂는다(백 외경 5.5, 흑 외경 5.0).
6. 건반 설치: 건반을 3.5 mm 앞쪽에 두고 스프링 위에 얹어, 살짝 누른 채 뒤로 3.5 mm 민다 → 크로스바가 훅 밑으로 들어가고 포크가 축에 "딱" 붙는다(자석).
7. y13 다운웨이트를 재서 와셔로 맞춘다. 센서 바·제어 기판은 v3 그대로. 뒤 커버를 끼운다.

**건반 1개 분리:** 뒤 커버를 뺀다(스냅) → 건반을 앞으로 3.5 mm 당긴다(자석 약 2 N 이상) → 들어낸다. 스프링은 기둥에 남는다. 공구 없음.

## 7. 소음 (모든 충돌)
- 다운스톱: 추가 든 건반이 펠트 3T(181 mm²)를 친다. 앞끝 0.3/0.6/1.0 m/s에서 2.9/11.7/32.6 mJ, 펠트 압축 25/38/50 %. 스프링 건반(m_eff 12 g)보다 5.4배 큰 에너지 → 더 묵직한 "툭".
- 업스톱(손을 뗄 때): 4.16 mJ(백) / 4.04 mJ(흑)가 훅 펠트 24 mm²로, 압축 40 %, 되튐 0.72 / 0.80 mm, 0.1 mm 안으로 가라앉기까지 97 / 102 ms.
- 스프링: 서지 157 Hz(백) / 103 Hz(흑). 멈출 때 "핑" 울림이 날 수 있다 → 가이드 기둥에 실리콘 그리스, 필요하면 기둥에 얇은 펠트 슬리브.
- 축: 자석이 포크를 축에 늘 붙여 슬롯 틈 0.05가 없어진다 → 덜걱임 없음. 흑건은 복귀 중 축 반력이 0을 지나지만 포크가 위아래를 모두 잡는다.
- 커플링 없음(레버 1개), 추는 완전히 갇힘.

## 8. v3 인터페이스 변경
- 리프·척추·클램프 나사·세트스크루·황동 원판·뒤 스톱 레일 → 없음. 그 자리(y190~205)에 핀 콤 + Ø5 축(y200, z33.5).
- 건반이 y204까지 길어짐(뒤 커버 밑). 백·흑 꼬리 벽은 y144에서 끝나고 뒤 팔은 z29.5 위로 올라가 제어 기판 부품(z20) 위 6.0 mm 이상 띄움.
- 스프링 기둥 12개(y138)를 프레임 바닥에. 리본 차선은 이 줄에서 바닥판 밑 EVA 홈으로 지나간다.
- 업스톱 훅·가이드 탭 위치: 백 y11.5~25 → y42.5~50.5, 흑 y77.5~91 → y104.25~115.
- 다운스톱 레일 윗면을 새 회전각에 맞춤(백 z10.90, 흑 z11.23). 백건 펠트 y1.5~10.5 → y3~12.
- 센서: 센서 바·기판·소자 위치 그대로. 자석만 0.57 / 0.23 mm 안으로 넣어 바닥 간격을 v3와 같은 4.7 / 4.9로 유지(이동량 6.69 / 8.68 mm로 v3보다 큼).
- 프레임 깊이 212, 전체 깊이 410, 뒤 커버 z59 그대로. 뒤 팔 윗면과 커버 가림판 사이 1.0.

## 9. 참고 구조와 비교해 뺀 것
- 그랜드: 해머·윕펜·잭·렙리션·댐퍼·백체크·밸런스 레일·앞 레일 핀·납 → 레버 1개 + 강철 추 1개 + 스프링 1개.
- GHS / Casio PX: 따로 도는 해머 레버와 그 축, 건반↔해머 연결 슬롯(떼는 소리의 원인), 고무 돔 스위치 → 없음.
- v3: 상시 약 6 MPa를 받던 PETG 리프, 척추 클램프, 세트스크루 → 없음.

## 10. 위험과 단계 0 시험
위험: 스프링 하중 공차(±10 % = ±12.7 g), 스프링 서지 울림, 바닥으로 갈수록 힘이 오름(백 +8.9 g, 흑 +12.2 g), 마찰이 작아 UW가 높음(43.6 g, 튀는 느낌), 강철 5.3 kg 추가, 흑건 관성이 백건의 약 0.57배, 자석 고정력 2 N은 추정값, 스프링 주문제작 가격 추정, 추 96개 절단.

단계 0 시험(하나라도 떨어지면 구조를 다시 본다):
1. 건반 2개(백·흑) 쿠폰 프레임: y13 DW 50±3, UW ≥ 40, 바닥 DW ≤ 62.
2. 센서 로그(5.9 kHz)로 손 뗀 뒤 40 % 복귀 ≤ 36 ms, 완전 복귀 ≤ 56 ms.
3. 포크 자석: 저울로 당겨 떼는 힘 ≥ 2 N, 1 N로 앞으로 끌어도 건반이 밀리지 않을 것. 모자라면 Ø6×3 자석 또는 닫힌 구멍 + 옥타브 단위 축 뽑기로 후퇴.
4. 100회 빠른 연타 녹음: 스프링 "핑", 업스톱 두 번 튐이 들리는지.
5. 스프링 10개를 설치 길이에서 하중 측정 → 편차로 분류·와셔 방식 결정.
6. 강철 추를 넣은 건반과 뺀 건반의 센서 곡선 비교, 이웃 건반을 눌렀을 때 신호 변화 ≤ 1 %.
7. 30일 정지 후 앞끝 높이 변화 ≤ 0.3 mm(펠트 압밀).
