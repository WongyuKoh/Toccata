# H1 — 뒤축 건반 + 무게추 해머 (카시오 PX-720 / 야마하 GHS 방식, 축소판)

## 1. 한눈에

- **건반**은 뒤끝(y171, z40)의 Ø3 SUS304 봉에 걸려 도는 출력 레버다. 이 점은 v3 리프의 순간 회전 중심 (171.04, 40.96)과 같아서, **y146 앞쪽(센서·자석·앞 펠트·가이드 탭·훅)은 v3와 한 치도 다르지 않다.** 자석 이동량도 백 6.12 / 흑 8.46 mm로 v3와 같다.
- 건반 밑에 매달린 **러그**(R3 둥근 끝, 백 y108, 흑 y96)가 **해머 코의 펠트 1T 패드**를 누른다. 해머는 두 번째 Ø3 봉(y127.55, z15)에 걸려 있고, 긴 뒷팔 끝(건반 봉 **뒤쪽**, y182–207)에 **9×25 평철 조각**(백 24 mm 42.4 g, 흑 22 mm 38.9 g + 2 mm 출력 심)이 있다.
- 누르면 해머 코가 내려가고 추가 11.9 mm 올라간다(10.4°). 손을 떼면 추가 떨어지며 러그를 밀어 건반을 올린다. 건반은 v3와 같은 **가이드 탭의 훅(펠트 3T)**에 닿아 멈춘다. 추는 해머 무게로 늘 러그를 누르고 있어서 **결합부 유격이 0**이다(블로그의 "덜걱" 원인이 없다).
- 세게 치면 추 윗면이 **스톱 레일 밑 펠트 3T**(z55.5)에 부딪혀 멈춘다(야마하 GHS·카시오의 윗 스펀지와 같은 역할).
- 흰 건반·검은 건반이 **같은 해머 하나**를 쓴다. 흑건 러그를 앞(y96)에, 백건 러그를 뒤(y108)에 두고 해머 봉 위치를 풀어서 두 색 모두 해머가 똑같이 10.43° 돌게 했다.
- 스프링은 없다(기본). 선택 사항으로 스톱 레일에 약한 보조 스프링 자리를 둔다(§9).

## 8. 조립과 분리

1. 프레임 바닥 EVA를 붙일 때 리본 길(폭 20, y77–182)을 오려 내고, 리본을 프레임 바닥 **밑**으로 지나게 한다(콤 핀이 바닥 위를 막기 때문).
2. 제어 기판(70×28로 줄임, 4067은 헤더 소켓 없이 평납땜, 부품 ≤ z13)을 y181–209에 놓고, USB-C는 v3처럼 뒷벽 개구로 낸다. 받침판(펠트 1T)을 나사 2개로 덮는다.
3. 두 콤에 Ø3 봉을 옆면에서 밀어 넣고 끝 마개로 막는다(PTFE 그리스 소량).
4. 평철을 24 mm(52개)·22 mm(36개)로 자르고 버를 없앤다. 흑건 해머에는 2 mm 심을 먼저 넣고 추를 압입 + 에폭시. 코 패드에 펠트 1T + 흑연.
5. 해머를 해머 봉 위에서 눌러 스냅(추는 받침판 펠트 위에 0.8 mm 뜬다).
6. 스톱 레일 밑에 펠트 3T 띠를 붙이고 뒷벽 위에 M3×10 3개.
7. 건반: 자석 압입(v3), 건반을 해머 코 위에 얹고 **4 mm 뒤로 밀면** 혀 슬롯이 건반 봉에 스냅되고 크로스바가 훅 밑으로 들어간다.
8. 커버를 스냅으로 끼운다. y13에서 47–50 g 확인(가벼운 건반은 해머 링 옆에, 무거운 건반은 건반 앞 바닥판에 텅스텐 퍼티).

**건반 하나 빼기(공구·커버 분리 없음):** 건반을 4 mm 앞으로 당겨 스냅을 풀고 앞을 조금 들어 앞으로 뽑는다. 혀 윗면 z43.5가 커버 앞 가림판(아래끝 z44.5, 흑건 노치 그대로) 밑을 지난다. 해머는 받침판 위로 내려앉는다.
**해머 빼기:** 건반을 뺀 뒤 커버와 스톱 레일(나사 3)을 떼고 위로 뽑는다.

## 9. 스프링 판단 ("필요하다면")

계산상 **필요 없다.** 선택 사항으로 스톱 레일에 Ø5 구멍을 뚫어 두고, SUS 선경 0.25 / 외경 4.0 / 18회 / 자유장 12.5(k 0.0355 N/mm) 압축 스프링을 넣으면 추 행정의 마지막 40 %에서만 추를 눌러(정지 시 하중 0) 완전 복귀가 백 63.6 → 56.4 ms, 흑 60.8 → 53.8 ms로 줄어든다. 대신 바닥 근처에서 힘이 48 → 69 g으로 커져 "턱"이 생기고, 일정한 손가락 힘(1.5 N)의 재타건 속도는 12.0 Hz 그대로다. 재타건을 빠르게 하는 것은 스프링이 아니라 m_eff를 낮추는 것뿐이다(§12 표).

## 10. 무엇을 뺐나

- 그랜드 대비: 해머 섕크·이스케이프먼트(잭·렛오프)·리피티션 레버·백체크·댐퍼·캡스턴 나사·밸런스 핀/펀칭·프런트 핀을 모두 뺐다. 건반 + 추 레버 하나, 축 2개만 남았다.
- GHS/카시오 대비: 러버 돔 스위치(홀센서가 건반을 직접 읽음), 러그를 가두는 홈(한쪽 접촉 + 해머 예압으로 바꿈), 금속 섀시, 해머 아래 스펀지(추는 평소 공중에 떠 있고 받침은 건반을 뺐을 때만 씀)를 뺐다.
- v3 대비: 리프·척추·척추 레일·세트스크루·M3×40 클램프·황동 원판·뒤 두 번째 바닥을 뺐다. 늘 휘어 있는 플라스틱이 없다(정지 응력 6 MPa → 최대 0.53 MPa).
- 방법 D 대비: 추를 건반 **밑**이 아니라 건반 봉 **뒤**에 두어 건반 높이가 z58 → z43.5 그대로이고, 해머 자석도 필요 없다(건반 자석을 v3 센서가 그대로 읽음). 필라멘트 7.6 → 4.8 kg.

## 11. v3와 바뀌는 인터페이스

- 뒤 커버 윗면 z59 → **z66**(+7), 커버 뒤 스커트 7 mm 길어짐, 뒷벽 윗면 z56.5 → z58.5(스톱 레일 자리).
- 제어 기판 70×50 → 70×28, 위치 y181–209(v3 y145.5–195.5), 4067 평납땜, 받침판 밑.
- 리본: 바닥 위 차선(x60–82) → 바닥 밑 EVA 홈.
- 프레임: 척추 레일(y196–209)·뒤 스톱 레일(y138–144) 삭제, 건반 콤 핀(y165–175)·해머 콤 핀(y118.5–136.5) 추가.
- 건반: 콤(7개·5개 한 덩어리) → 낱개. 리프 대신 혀 슬롯, 밑에 러그.
- y146 앞(센서 바, 자석, 앞 펠트, 흑건 스톱, 탭·훅)과 폭 1254·깊이 410은 그대로. 건반 보관함(338.8×172×77)에는 낱개 건반을 x 방향으로 눕혀 넣는다.

## 12. 왜 커버가 올라가나, 그리고 대안

- 추가 해야 할 일은 "손가락 일 = BW × 행정 + 건반 위치에너지"를 위치에너지로 갚는 것이다. 9×25 직사각 추의 높이와 상승량을 나눠 쓰면 가능한 위치에너지는 ρ·w·L·(B/2)²에 비례한다(B = 받침판 z16.5에서 스톱 펠트까지). 같은 형상에서 커버 z59면 추 17 mm·DW 30.4 g, z62면 20 mm·37.8 g, z66이어야 24 mm·47.7 g이다. 추 밑의 제어 기판이 B를 7.5 mm 먹는다.
- 트레이드오프(건반 봉 y171, DW ≥ 47.5가 되는 가장 낮은 커버): 러그 y106 → 커버 z64.5, 추 35.3 g, m_eff 109, 완전 복귀 68.3 ms, 11.2 Hz / y108 → z66.0, 42.4 g, 92.5, 63.6 ms, 12.0 Hz / y110 → z68.0, 49.5 g, 81.6, 60.3 ms, 12.6 Hz / y112 → z71.0, 57.4 g, 75.2, 57.7 ms, 12.9 Hz (재타건은 1.5 N 기준).
- 대안 H1-B: 건반 봉을 y164로 당기고 9×32 평철(L32)을 쓰면 커버 z61(+2)에서 DW 47.0, m_eff 96.6, 완전 복귀 65.1 ms, 최소 틈 1.09. 대가는 앞뒤 힘 비 1.95 → 2.04와 자석 이동 6.12 → 5.95, 그리고 v3 앞쪽 운동이 조금 달라지는 것.

## 13. 위험과 단계 0 시험

위험: (1) 러그–패드 미끄럼(행정당 백 1.50, 흑 2.23 mm)의 마찰 계수가 불확실하다 — μ 0.10/0.25/0.35에서 백 DW 46.3/50.5/53.3, UW 37.1/32.6/29.5. 패드 펠트가 10⁶회에 닳을 수 있다. (2) 스톱 레일은 ff 타건마다 50–70 N을 받는다(굽힘 6.1–8.6 MPa, 순간). (3) 해머가 옆으로 ±0.84 mm 흔들려 이웃 링과 최악 0.94 mm — 비비면 소리. (4) 평철 88조각 절단 품질·링 압입. (5) 커버 +7 mm. (6) 훅 펠트가 오래 눌리면 건반 높이가 v3처럼 조금 올라감(훅 하중 백 0.77 N). (7) 1.5 N 손가락 힘에서 재타건 12 Hz.

단계 0 (반증 시험, 약 2일):
1. 3건반 쿠폰(백·흑·백, 프레임 조각 + 진짜 봉·추): y13 DW/UW를 동전 추로 측정. **UW < 25 g 또는 DW−UW > 16 g이면 불합격.**
2. 휴대폰 240 fps로 바닥에서 손 뗀 뒤 완전 복귀 측정. **75 ms를 넘거나 복귀 때 "덜걱" 두 번 소리가 나면 불합격.**
3. 패드 재료 3종(펠트 1T / 펠트 + 흑연 / PTFE 테이프) 경사판 마찰 계수 비교.
4. 스톱 레일 조각에 10 N 타건 10⁴회(캠 지그) → 균열·펠트 영구 눌림 < 0.3 mm.
5. 건반 혀 스냅 빼는 힘 2–5 N, 해머 보스 스냅, 봉 리밍 뒤 24장 핀 정렬.
6. ff 연타 소리 녹음을 v3 리프 쿠폰과 비교.
