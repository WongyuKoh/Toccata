# Toccata v4 W1+ 전자부 회로도 (hardware/pcb)

**W1(v4 W1+, 시소 건반 + 무게 레버) 설계의 전자부 회로도**입니다. W1 설계 문서는 센서 바·센서 기판·제어 기판·리본·USB를 이전 설계에서 그대로 가져온다고만 적었고, 회로는 글과 블록 배선도로만 있었습니다. 이것을 W1 좌표 모델(r4.3~r4.5)에 맞춘 **실제 회로도**로 만들었습니다. 부품 번호, 핀 번호, 넷 이름, 값, 연결이 모두 들어 있어 KiCad 같은 CAD에서 그대로 다시 그릴 수 있습니다.
기준은 W1 r4.5(2026-09-29) 좌표 모델 `hardware/mechanical/key-action-v4/model/geometry.json`(circuit_r43·circuit_r44 블록)·`metrics.json`과 설계 문서 `…/DESIGN.md`이고, 글 사양에 아래 **변경 △1~△16**을 더했습니다. 2026-09-28 W1 세션의 r4.2~r4.3 최종 자료(끝 부속 센서 바, USB 선반 홈, 프레임 레일·리브, W1 검증 요청)와 v4 구매 목록을 다시 대조해 △13~△15와 구매 목록 수정 목록을 더했습니다. 2026-10-01에는 R31 터치스크린(사용자 선택 B1 = Waveshare 7-DSI-TOUCH-C)의 전원·DSI 연결과 전원 예산을 △16으로 더했습니다(개정 C).

## 규칙

- **부품 번호.** 시트 번호 × 100입니다(KiCad의 "First free after sheet number × 100"). SB는 U201~, MB는 A301~, EL/ER은 40x/41x, PB는 50x, PS는 551, 전원은 60x, 오디오는 70x입니다.
- **보드 쪽 부품은 보드마다 번호가 같습니다.** 7개 모듈은 같은 기판을 7장 만들고 ID 점퍼만 다르게 닫습니다.
- **U, A, J, P, X의 뜻.**
  - U = 칩
  - A = 구매 모듈(RP2040-Zero, 먹스, PD 트리거, 강압, 앰프, 동글)
  - J = 기판 쪽 커넥터나 패드
  - P = 선 끝 플러그
  - X = 선 대 선 커넥터(JST-XH, XT30)
  - 두 커넥터가 맞물리는 곳에는 `>>` 표시를 그렸습니다. **KiCad에서는 연결이 아닙니다**. 그래서 맞물리는 양쪽 핀에 같은 넷 이름(라벨)을 붙여 두었습니다.
- **전원 넷.** `+3V3`, `GND`, `+20V`, `+5V1`은 전원 심볼로 그렸습니다. KiCad에서 로컬 라벨 "GND"는 전원 넷에 붙지 않으므로 반드시 전원 심볼을 씁니다.
  - `+20V`와 `+5V1`은 표준 라이브러리에 없습니다. 프로젝트 전원 라이브러리에 추가하세요(`+24V`를 복사해 이름을 바꾸면 됩니다).
  - EL·ER 쪽 3V3는 O1·O7 제어 기판의 3V3 레일이라 `+3V3_EL`, `+3V3_ER`로 나눴습니다(프로젝트 전원 심볼로 추가). 끝 부속 신호는 `EL_A0`, `EL_AS0`, `EL_B0`, `ER_C8`입니다.
- **오디오 신호 GND(`AGND`).** 잭 슬리브와 HPF 1 kΩ의 GND를 앰프 IN G 단자로만 모읍니다(△10). 전원 GND와는 앰프 보드 안과 USB를 통해 이어집니다.
- **모듈 패드 번호.**
  - RP2040-Zero는 `dj505/RP2040-Zero-KiCAD` 라이브러리 번호를 따릅니다: 1~9 왼쪽 위→아래, 10~18 오른쪽 위→아래, 19~23 아래 왼→오. Waveshare 회로도 P1 번호는 표에 같이 적었습니다.
  - 4067 모듈은 1~16 = C0~C15(J1)이고, 17~24 = J2 1~8(GND, VCC, EN, S0, S1, S2, S3, SIG)입니다.
- **3.5 mm 잭**은 KiCad `AudioJack3_SwitchTR`처럼 핀 번호가 글자(T, TN, R, RN, S)입니다. PJ-313은 판매자마다 1~5 번호가 달라서, 통전 검사로 글자를 찾아 씁니다.
- **XT30**은 KiCad 풋프린트대로 패드 1 = −, 2 = +입니다. 커넥터의 납작한 면이 +입니다.

## 도착 후 확인할 것 (검토의 bring-up 목록 요약)

1. **PD 트리거.** 무부하로 전원마다 20 V가 나오는지 잽니다. HUSB238은 ISET이 열려 있으면 3.25 A를 요구해서, 20 V 3 A 보조배터리는 15·12 V나 5 V로 떨어질 수 있습니다.
2. **XL4016.** 무부하로 5.10~5.15 V에 맞추고 가변저항을 고정한 뒤 연결합니다. MT666 선과 허브 선의 극성도 확인합니다.
3. **PJ-313 ×3.** 플러그가 없을 때 T–TN, R–RN이 닫혀야 합니다. 노멀 접점이 없는 제품이면 헤드폰 차단(R15)을 할 수 없습니다.
4. **RP2040-Zero 복제품.** LDO 표시를 확인합니다(5핀 RT9013/ME6217이면 괜찮음). O1의 3V3 전류는 60~130 mA가 정상입니다.
5. **센서.** 자석 없이 OUT이 1.59~1.71 V(DRV5055 영점)이고, S극을 표시면에 가까이 하면 올라가야 합니다. 건반을 얹은 쉼에서는 백 약 1.78 V, 흑 약 1.72 V, 끝까지 누르면 백 약 2.31 V, 흑 약 2.39 V입니다(±10 %). EXT를 뺐을 때는 0.15 V 아래여야 합니다.
6. **페달.** 꽂은 상태에서 링–슬리브가 3.05 V 이상이고, 뺐을 때 팁이 약 0 V여야 합니다.
7. **앰프.** 36 dB 이득인지 확인하고 소프트웨어 음량 상한을 정합니다. 스피커 Re가 6~7 Ω인지(4 Ω 판매분 주의) 잽니다.
8. **허브 역급전.** Pi 선을 뺐을 때 Pi 5V 핀이 0 V여야 합니다.
9. **USB-C 위치·케이블.** 산 RP2040-Zero(복제품)의 리셉터클이 오른쪽 모서리에서 4.67 mm인지, 제로 가장자리 밖으로 몇 mm 나오는지 잽니다. 핀 헤더로 세운 제로에 실제 케이블을 10번 꽂고 빼 봅니다(몰드 ≤ 12.5 × 7.6 × 25, W1 시험 19).
10. **화면 전원(△16).** 동봉 전원선의 2.54 3핀 하우징이 1 빨강 5 V · 2 빈 칸 · 3 검정 GND인지 통전 검사로 확인한 뒤 점퍼를 꽂습니다. 화면 MX1.25 쪽 5 V를 부하 때 잽니다(점퍼 두 단 왕복 강하 계산 약 0.05 V). 최대 부하(FluidSynth + 화면 밝기 100 % + USB 장치)에서 `vcgencmd get_throttled` = 0x0(Pi USB-C 입력 약 2.0 A, D16). 화면 켬·끔, 밝기 0·100 %에서 센서 유휴 흔들림을 다시 잽니다(D14). config.txt에는 `dtoverlay=vc4-kms-dsi-waveshare-panel-v2,7_0_inch_c` 한 줄을 넣습니다(CAM/DISP 0이면 `,dsi0`).
