# Toccata 전자부 회로도 · 기판 · 배선 (hardware/pcb) — 개정 E

악기 전자부의 **최종 회로도와 기판·배선 도면**입니다. 부품 번호, 핀 번호, 넷 이름, 값, KiCad 심볼·풋프린트, 구멍 좌표, 선 길이가 모두 들어 있어 KiCad 같은 CAD에서 그대로 다시 그리거나 만능기판에 바로 옮길 수 있습니다.

- 기준: W1 r4.5 좌표 모델(`hardware/mechanical/key-action-v4/model/geometry.json` circuit_r43~r45, `DESIGN.md`), L2 본체·전자부 CAD(`hardware/mechanical/cad`, 2026-10-07 빌드 — `build_all.collect()`만 부름), 최종 구매 목록(plan C, `최종본/01_구매목록/Toccata_학교_사비_구매목록_2026-10-08.xlsx`, `hardware/bom/final-bom/data.json`·`state_main.json`, `docs/report/toccata-v4/data/final_items.json`).
- 도면 15장: 회로도 SCH-01~07 + 기판·배선 BRD-01~08 (A3, mm). 모두 한 소스(`src/`)에서 만들고, 만들 때 **그린 선·라벨로 연결을 다시 계산**해 의도한 넷리스트와 대조합니다(ERC 대용). 개정 E 빌드: 15장 모두 연결 오류 0, 글자 겹침 0, 기판 배선 검사 0 — BRD-03(PB)·BRD-07(J702·PS)·BRD-02(SB OUT·전원 → J201)·BRD-08(MB 아랫면): 기판에 패드가 있는 넷마다(선이 없는 넷도) 패드가 한 덩어리로 이어지는지, **피복 가닥은 두 끝에서만 이어지고 주석 맨선은 지나는 패드마다 이어진다**는 규칙으로 보고, 다른 넷 패드(납땜 자리)·받침 기둥·잭 자리를 지나지 않고, 다른 넷 맨선끼리 닿지 않음(MB는 두 선이 한 칸을 같이 쓰지 않음까지). 기판 도면에 적힌 부품 번호는 모두 bom.csv에 있음.
- 개정: A 2026-09-28 첫 판(△1~△12) · B 09-29 W1 r4.5 대조(△13~△15) · C 10-01 터치스크린(△16) · D 10-07 전지 입력·XT60(△17·△18) · **E 10-08 최종 구매에 맞춤 + 기판·배선 도면 6장(△19~△26) + 2차 검토(△27~△30)**. 개정 E에서 SCH-01·03·04·05·06·07, BRD-01·02가 바뀌었고 SCH-02는 B 그대로입니다. 같은 날 검토로 고친 것: △24 작은 기판 BRD-07(J702 메모가 1 µF를 TN·RN에 잇게 적혀 있던 것 바로잡음), △25 W601 전체 길이 규칙, △26 SB·MB 배선 경로(BRD-08), USB 선 길이를 선마다(1 / 0.5 / 0.3 m, CAD), 앰프 단자 여유 50 mm, 허브 충전 전용 포트 확인. **2차 검토(△27~△30)**: SB J201 전원 4가닥, PB·J702 피복 가닥 끝 규칙(GP26·잭 슬리브), W701 길이(CAD 경로), 12 AWG 꼬리 36 mm(이음을 굽힘 뒤로).

다시 만들기 (저장소 루트에서):

```
python3 hardware/pcb/src/build.py     # CAD 읽기(따로 프로세스) → 도면 15장 + CSV + 검사, 문제 0이면 종료 코드 0
python3 hardware/pcb/src/page.py      # '01 회로도' 탭 조각 page/circuit.{html,css,js} + assets.txt + 받기 파일
```

`build.py --no-cad`는 저장된 `netlist/cad_centre.json`을 씁니다. CAD 쪽 `build_all.py`의 main()은 부르지 않습니다(stl/print를 지움).

- **U, A, BT, J, P, X, W.** U = 칩, A = 산 모듈, BT = 전지 팩, J = 기판 쪽 커넥터·패드, P = 선 끝 플러그, X = 선 대 선 커넥터(JST-XH, XT60), W = 선. 두 커넥터가 맞물리는 곳의 `>>`는 KiCad에서 연결이 아니므로 양쪽 핀에 같은 넷 이름을 붙였습니다.
- **전원 넷.** `+3V3`, `GND`, `+12V8`, `+5V1`, `+5V_PI`, `+3V3_EL`, `+3V3_ER`은 전원 심볼(뒤 다섯은 프로젝트 전원 라이브러리에 `+24V`를 복사해 이름만 바꿔 추가). `+12V8`은 스위치 뒤 전지 버스(공칭 12.8 V, 10.0~14.6 V), 스위치 앞은 로컬 라벨 `VBAT`(전지 + → XT60 → 퓨즈)·`VBAT_F`(퓨즈 → 스위치).
- **별 접지점** = XL4016 IN− 단자: 전지 −(W601 검정)와 앰프 GND(W602c 검정)가 여기서만 만납니다(△5). 오디오 입력 쪽 GND는 `AGND`로 나눠 앰프 IN G 단자로만 모읍니다(△10).
- **모듈 패드 번호.** RP2040-Zero = `dj505/RP2040-Zero-KiCAD` 번호(1~9 왼쪽 위→아래, 10~18 오른쪽, 19~23 아래 — 아래 줄은 헤더 없음), Waveshare P1 번호는 표에 같이. 4067 모듈 = 1~16 C0~C15, 17~24 J2(GND, VCC, EN, S0~S3, SIG).
- **3.5 mm 잭 PJ-313**은 핀 번호가 글자(T, TN, R, RN, S — KiCad `AudioJack3_SwitchTR`). 판매자마다 1~5 번호가 달라 통전 검사로 글자를 찾습니다.
- **KCD1-104(SW601)** = KiCad `Switch:SW_DPST`(1–2 회로 A, 3–4 회로 B). 두 회로를 나란히: 입력 1·3, 출력 2·4 (W602j). 실물에서 한 회로의 두 단자는 켬 상태 통전으로 찾습니다(CAD는 같은 x 열의 위·아래 단자로 가정).
- **XT60**: KiCad 풋프린트대로 패드 1 = −, 2 = +. 커넥터가 한 종류라 전원 XT60(팩 리드 X605, W601 X606, 벤치 어댑터) = **빨강 수축 튜브**, 스피커 XT60(X703~X706) = **파랑 수축 튜브 + "SPK"**(△18). **W601(△25)**: 홀더 −x 끝에서 XT60 수 뒤끝까지 이은 전체가 68 mm 이하(CAD mismate: C-PWR-IN 경로 57.6 + 10)여야 왼쪽 스피커 XT60 암(직선 94.4 mm)에 닿지 않습니다 = 홀더 12 AWG 꼬리 36 mm + XT60 리드 40 mm − 이음 겹침 10 ≈ 66 mm(CAD 경로 59.8, 여유 약 6). **12 AWG 꼬리(△30)**: 두 꼬리 모두 36 mm = R15 굽힘 23.5 + 이음 자리 12(CAD) — 10 mm 겹침이 홀더 끝에서 26~36 mm, 굽힘이 끝난 뒤에 옵니다(짧게 자르면 이음이 R15 굽힘 안에 들어감). W602a 16 AWG = 105 mm(KCD1 입력 탭까지 CAD 114.1 + 탭 위 5 + 여유 10, 겹침 시작에서), W601 검정 연장 = 195 mm.
- **선 길이.** `harness.py` 한 곳에서: CAD 경로 = `cad_extract.py`가 읽은 electronics.py 중심선 길이(LENGTHS), 자르는 길이 = 경로 + 20 mm(벗김 5 × 2 + 여유 10), 5 mm 올림. 이음(S…) = 10 mm 꼬아 납땜 + 수축 튜브 20 mm. CAD가 그리지 않은 선은 '추정'과 근거를 적었습니다. **헤드폰 선(△29)**: W701·W702는 CAD에 선이 없어 `cad_extract.py`가 모델 형상으로 직각 경로(위쪽 어림)를 잽니다 — J701 다리 → 볼 홈(x−12.6~−4.1, z2.5~7.5) → 통로 바닥(z1.75, y222) → 동글 플러그 뒤(x650 z21.75) = W701 905 mm, J702 플러그 뒤(x520 z25.6) = W702 778 mm. W701은 플러그 뒤끝에서 1.0 m(경로 + 20 + 추정 여유 50, 50 mm 올림), 남는 토막에서 W707. **앰프 단자 여유**: XH-A232는 스피커 단자 L+·L−·R+·R−가 한 가장자리에 한 줄, VCC·GND가 반대 가장자리(research/audio.md 1.1)인데 CAD는 L 단자를 −x 끝, R 단자를 +x 끝에 두었으므로, W602c·W703·W705는 50 mm 더 자르고 받은 보드로 단자 자리를 확인합니다(CAD 쪽에서 단자 자리를 고치면 다시 계산). W606·W607은 CAD 경로가 아니라 제품 길이 200.
- **USB 선(W201~W208)**: 선마다 길이가 다릅니다 — CAD `spec/body_L2.json` cable_duct.cables std_m을 `cad_extract.py`가 `usb_std_m`으로 읽음. 허브 710U3는 10포트 중 1개가 충전 전용이고 포트마다 스위치가 있어, 충전 전용 포트가 0·1번(비움)인지 확인하고 아니면 보드를 옮깁니다(`harness.hub_move_rows`: 옮긴 뒤 길이 = CAD 경로에서 가로 길이만 바꾼 추정).
- **만능기판 격자.** MB = 제로 핀 격자(x = 76.52 + 2.54i, y = 173.59 + 2.54j, 지그 P-MB), PB = 지그 P-PED 격자(x = 475.23 − 2.54j, y = 245.27 + 2.54i). 페달 보드의 A501은 CAD 상자보다 x −0.55 · y −1.62(핀이 구멍에 들어가는 가장 가까운 자리, △22). J702 기판 x = 506.27 + 2.54i, y = 256.27 + 2.54j; J501 조각 x = 451.27 + 2.54i, y = 317.77 + 2.54j(모델 좌표, 모서리는 구멍 사이 가운데); PS 조각 = 로컬(왼쪽 아래 구멍 0, 0). PJ-313 다리는 2.54 격자가 아니라(SHOU HAN 도면 1.8·3.2·3.5 mm) 잭 자리(점선) 안에서 꽂고 T·R·S 모음 패드까지 짧게 잇습니다.
- **배선 경로**: 만능기판 아랫면 선은 1.27 격자 위로만 지나고(구멍 사이 반 칸 또는 빈 구멍), 납땜할 패드 위는 지나지 않으며, 두 선이 한 칸을 나란히 쓰지 않습니다(직각 겹침은 피복이라 허용). **피복 가닥은 두 끝만 벗겨 끝의 패드(또는 같은 넷 맨선)에 납땜** — 가닥 중간은 아무것도 잇지 않습니다. 주석 맨선(굵은 실선: 버스·레일·짧은 다리)은 지나는 패드마다 납땜합니다(△28). SB의 OUT 12가닥은 같은 반 칸 줄을 나란히 눕습니다. MB 49가닥은 `mbroute.py`가 찾고(넷마다 최소 신장 트리, 혼잡 협상 경로 찾기 + 다시 놓기) 독립 검사합니다.
