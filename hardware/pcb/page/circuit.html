    만드는 순서와 확인

    1. PJ-313 3개의 다리 글자(T·TN·R·RN·S)를 통전으로 찾는다. J701은 왼쪽 볼 포켓(기판 없음, 다리에 직접 납땜), J702는 J702 기판(BRD-07)에.
    2. BC256 3 m를 가운데에서 잘라 두 반쪽: W701은 플러그 뒤끝(선이 몰드에서 나오는 곳)에서 1.0 m로 자르고(CAD 경로 약 905 mm → J701 T·R·S), 남는 약 0.46 m에서 W707(300)을 자른다. 자르기 전에 볼 홈 → 통로 → 동글 경로에 대 본다. W702(J701 TN·RN·S → 플러그, 경로 약 778 mm)는 1.5 m 반쪽 그대로.
    3. J702 기판: 잭 T·R·S 다리 → 모음 패드, T 모음 → C701·C702(나란히) → 패드 L, R 모음 → C703·C704 → 패드 R, R701·R702 1 kΩ은 출력 → G(AGND 줄). TN·RN 다리는 어디에도 잇지 않는다. AGND는 앰프 IN G에서만 GND와 만남.
    4. W703·W705: 앰프 스피커 단자 → XT60 수 SPK 리드와 이음(50 mm 여유 — 단자 자리는 받은 보드로), W704·W706: XT60 암 리드 → 상자 안 짧은 선 → 유닛. 모두 파랑 수축 + SPK, 좌우 같은 방향(+ = 빨강).
    5. 확인: T 모음–L 패드 열림, C703.1 ↔ R702.1 ↔ W707 R 패드 = 0 Ω, L–G = 1 kΩ, R–G = 1 kΩ, 스피커 Re 6~7 Ω, 헤드폰을 꽂으면 스피커가 꺼짐. 소프트웨어 음량 상한은 최대 출력 약 8 W/ch(입력 약 0.13 Vrms)에서 찌그러지지 않게.
