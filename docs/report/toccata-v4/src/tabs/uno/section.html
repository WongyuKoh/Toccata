01b 아두이노 버전 — 노트북에서 실행

Pi 버전(01 회로도, 개정 E)과 건반·센서·출력물·전지·앰프·스피커는 같고, 건반을 읽는 칩과 메인 프로그램이 도는 곳만 다른 두 번째 구성입니다. RP2040-Zero 8개와 Raspberry Pi 5 대신 Arduino Uno 1개가 88건반과 페달을 모두 읽어 USB로 노트북에 보내고, 피아노 음원과 리듬게임은 노트북에서 돕니다. 두 버전은 기판 몇 군데만 달라 어느 쪽으로든 다시 바꿀 수 있습니다.

도면 U-01~U-04 (개정 U1, 2026-11-23) — 그린 선으로 연결을 다시 계산해 의도한 넷리스트와 맞춘 결과 연결 오류 0 · 글자 겹침 0. 원본: hardware/pcb/src/uno_sheets.py → hardware/pcb/uno/. 아직 실제로 만들어 보지 않은 설계라 첫 조립 때 아래 ‘처음 켤 때 확인’을 지켜 주세요.

세기 표현은 Pi 버전보다 거칩니다. 우노의 ADC 하나로 88개를 차례로 읽어 한 건반을 약 1.5 ms마다 봅니다. 센 타건은 그 사이에 바닥까지 가므로, 펌웨어는 두 번 읽은 자석 위치 차이로 속도를 구합니다. 리듬게임과 시연에는 충분하지만 아주 여린 소리·아주 센 소리의 구분은 Pi 버전보다 덜 섬세합니다.

세팅 순서

  1. 옥타브 기판 바꾸기 — 제로를 헤더째 뽑고, 먹스 EN–GND 선을 끊어 J303.8로. 제로 자리에 J303 패드 10개를 두고 W80m 리본을 납땜(U-02).
  2. UB 만들기 — 만능기판 조각에 J801~J807 박스 헤더, 저항 19 + 2.2 kΩ + 10 kΩ 2개, 페달 부품(Pi 버전 PB에서 옮김), J809(U-03). 리본 UB 쪽 끝에 IDC 소켓을 눌러 끼우고 O 번호를 적습니다.
  3. 전원 — XL4016 출력을 무부하로 5.10~5.15 V에 맞춘 뒤 W810으로 UB J809에(U-04). Pi·허브·화면 전원선은 만들지 않습니다.
  4. 우노 펌웨어 — Arduino IDE에서 firmware/uno/toccata_uno/toccata_uno.ino를 열어 보드 “Arduino Uno”로 올립니다(firmware/uno/README.md).
  5. 노트북 설치 — 저장소 루트에서 ./sw/setup-laptop.sh (FluidSynth · Python 패키지).
  6. 실행 — 우노 USB를 꽂고 전지 스위치를 켠 뒤(건반은 모두 올린 채) ./sw/toccata-bridge → 다른 창에서 ./sw/toccata-midi synth(피아노 소리) 또는 ./sw/toccata-game(리듬게임). 브리지가 가상 MIDI 입력 “Toccata Uno”를 만듭니다.

처음 켤 때 확인

  • 켜는 순서: 노트북 USB → 전지 스위치. 끌 때는 반대. 버스가 꺼지면 우노가 A2로 알아채고 핀을 놓습니다.
  • 우노 5V 핀을 +5V_B에 잇지 않습니다. GND만 함께 씁니다.
  • 리본 1번(빨간 줄)이 J303.1·J80m.1(GND)인지 통전으로 확인한 뒤 꽂습니다.
  • 노트북을 충전하며 칠 때 ‘웅’ 소리가 나면 3.5 mm 접지 고리 차단기를 연장선에 끼우거나 충전기를 뺍니다.
  • 브리지가 포트를 열면 우노가 다시 시작하며 쉼 값을 읽습니다 — 브리지를 켤 때 건반을 모두 올려 둡니다.
  • 브리지 창에서 s + Enter로 건반별 쉼 값·남은 메모리·초당 스캔 수를 봅니다(실측 스캔 수는 여기서 처음 확인). 쉼 값이 5 V 기준 범위 밖이면 그 모듈 리본·센서를 확인합니다.
  • Arduino IDE가 “메모리 부족” 경고를 띄웁니다(전역 변수 75 %). 정상이며, 남은 메모리는 s 상태표에 나옵니다.
  • Pi 버전으로 되돌리기: 제로를 다시 꽂고 EN을 GND에, USB 선·허브·Pi를 다시 연결합니다. 펌웨어는 버전마다 따로라 서로 건드리지 않습니다.
Pi 버전 기판 그대로도 노트북에서 돌릴 수 있습니다 — 허브 업스트림 선(W209)을 Pi 대신 노트북에 꽂으면 옥타브 보드 8개가 USB-MIDI로 바로 보이고(브리지 불필요), 같은 ./sw/toccata-midi synth · ./sw/toccata-game로 칩니다.
