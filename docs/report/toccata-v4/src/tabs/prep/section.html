계산 방법과 출처

전체 준비율 = 셈에 들어가는 줄마다 (준비 수 ÷ 필요 수, 1이 넘으면 1)를 더해 줄 수로 나눈 값입니다. 88개짜리 줄과 1개짜리 줄이 같은 무게입니다. 퍼센트는 버림이라 모든 줄이 끝나야 100 %가 됩니다.

소수 = 길이 줄(단위 m)은 0.1 m까지 적습니다. 나머지 줄은 개수라 소수를 적으면 버립니다(필요 2개에 1.5를 적으면 1개). 반올림하지 않으므로 모자란 줄이 다 됨으로 바뀌지 않습니다.

기본으로 셈에 넣는 줄 = A 부품 99줄 + B 출력물 96줄 + C 가공·조립 59줄 = 254줄. D 공구 21줄은 위 칸을 켜야 들어갑니다. 선택 줄(A의 보험·시험용 2줄, B의 stl/print_extra 21줄)은 그 줄의 '준비율에 넣기'를 켜야 들어갑니다.

출처 = A·D: 최종 재료 목록 data/final_items.json (주문 수와 설계가 쓰는 수). B: hardware/mechanical/cad/manifest.json의 출력 파일 (파일 이름 끝 개수만큼 뽑음). C: CAD 모델(build_all.collect)의 부품 수와 회로 선 목록(cables.csv)·부품표(bom.csv). 줄 목록은 src/build_prep.py가 2026-10-16 20:18에 만들었습니다.

저장 = 준비 수는 이 페이지의 공유 저장소(prep/state)에 줄 번호별로 저장됩니다. 공유 저장소에 연결되지 않은 화면(미리보기 등)에서는 이 기기에만 저장됩니다.
