동작 시뮬레이션

완성된 악기에서 건반 하나를 누르면 기구, 센서, 회로, 소리, 전원이 어떻게 움직이는지 보여 줍니다. 움직임은 꾸민 애니메이션이 아니라 검증된 계산 모델의 기록을 그대로 재생한 것이고, 신호와 전원 숫자는 회로도 개정 E의 부품 번호와 값에서 가져왔습니다.

이 시뮬레이션은 건반 액션 계산 모델 model_v4.py(W1+ r4.5)의 4자유도 동역학을 4 µs 간격으로 돌린 기록입니다. 대표 건반 백건 D와 흑건 C#를 계산했고, 출력용 STL과 같은 좌표(geometry.json)의 단면을 움직입니다. 계산값은 검증 결과 파일(metrics.json)과 6자리까지 같습니다.

가정: 업스톱 패드는 설계값(미세셀 우레탄 6T + 펠트 1T)으로 계산했습니다. 산 패드는 PORON 5T + 펠트 1T라서 패드 면 위치는 같지만 힘과 튕김은 단계 0 시험에서 다시 확인합니다. 자기장은 원판 자석 축 위 식(오차 약 ±10 %), 센서 출력은 DRV5055A2 3.3 V(1.65 V + 30 mV/mT), ADC는 12비트(3.3 V 기준)로 셈합니다. note-on 문턱(자석 90 % 내려감), 속도를 재는 구간(자석 50 → 90 %), MIDI 벨로시티 곡선, 재무장선에서 note-off를 보내는 규칙은 펌웨어를 만들기 전의 가정입니다. 건반마다 읽는 빠르기(kHz)도 추정입니다: 먹스 채널마다 4 µs 기다리고(SCH-03 주 7) 2 µs 변환한다고 잡았습니다(채널당 6 µs).

1건반 한 개: 누름 → 유지 → 놓음

손가락이 정한 속도로 건반을 치고(앞끝이 바닥 펠트에 닿는 순간의 속도), 바닥에서 1 N으로 약 0.2초 누르고 있다가 손을 뗍니다. 가장 여린 경우는 0.8 N으로 천천히 누르는 경우입니다. 시간 0~5 ms는 쉬는 자세이고 5 ms에 손가락이 닿습니다. 시간 막대를 끌면 원하는 순간을 볼 수 있습니다. 바닥에서 누르고 있는 구간은 그래프와 재생에서 줄여 보여 줍니다. 주황 테두리는 지금 힘을 받고 있는 접촉면입니다.

버튼을 누르고 있는 동안 건반이 내려가 바닥에 머물고, 손을 떼면 돌아옵니다(스페이스나 엔터 키도 됩니다). 새로 계산하는 것이 아니라 위에서 고른 세기의 기록을 이어 붙입니다: 누르면 기록의 0 ms부터 놓기 직전까지 재생하고 그 자리에 멈춥니다. 떼면 기록의 ‘놓음’ 순간으로 건너가 돌아오는 부분을 재생합니다. 바닥에 닿기 전에 떼면, 돌아오는 기록에서 자석 높이가 지금과 같은 첫 순간으로 건너뜁니다(근사). 재생 빠르기는 위 설정을 따릅니다.

세기별 결과 백건 D

‘추정 속도’는 펌웨어처럼 자석이 50 %에서 90 %까지 내려가는 시간으로 잰 앞끝 속도입니다(행정비 백 1.91, 흑 1.18, SCH-03 주 9). 행정 가운데의 속도라서 바닥 펠트에 닿는 순간 속도와 조금 다릅니다. 여리게 칠수록 레버가 패드에 먼저 닿아 건반이 마지막에 느려지므로 추정이 더 크게 나오고(특히 흑건과 0.8 N 누름), 세게 칠수록 행정 아래쪽에서 더 빨라지므로 추정이 조금 작게 나옵니다. 흑건을 0.8 N으로 누르면 앞끝이 바닥 펠트에 닿지 않고 멈춥니다(1 N에서도 펠트 위 0.27 mm, 설계 그대로). 그래서 그 칸에 ‘닿지 않음’이라고 적었습니다.

검증된 값 (metrics.json에서 그대로 옮김)

ADC 값은 이 페이지의 식으로 다시 셈한 것입니다. 쉼, 재무장, 1 N 바닥은 회로 README 표와 같고, 강체 바닥은 표(2862 / 2962)보다 3 / 2 코드 큽니다(0.1 %, 자기장 식 오차 ±10 %보다 훨씬 작음).

2한 음의 신호: 건반에서 스피커까지
