## 0. 한 장 요약

```
 건반 1개 = 단일 PETG 프린트
 ┌──────────────────────────────────────────────────────────────────┐
 │ [키 본체] ──◆ 교차 판스프링 피벗 ──[꼬리 스파인]──[12단 사행 판스프링]│
 │   앞끝 y=0        y=165 (회전 전담)      z=7~11      y=180~218      │
 │                                                     (복귀력 전담)   │
 └──────────────────────────────────────────────────────────────────┘
        ▲ 자석 Ø3×2 @ y=110              ▲ 자유단이 예하중 레일을 위로 밀고
        ▼ 3.600 내려가 SS49E에 접근        그 반작용이 꼬리를 아래로 눌러 앞끝을 든다

 키베드가 제공하는 것: ① 피벗 앵커 포켓 ② 예하중 레일(높이 조절) ③ 업스톱/다운스톱
                      ④ 가이드 콤 3줄 ⑤ PCB 자리
```

**세 가지 설계 원칙**

| 원칙 | 이유 |
|---|---|
| **① 회전축과 복귀력을 분리한다** | 하나의 플렉셔가 둘 다 하면 예압 각이 커져 크리프와 피로가 동시에 나빠진다. 피벗은 예하중 0(평균응력 0), 복귀 판은 회전 0 |
| **② 변형을 얇게가 아니라 길게 분산한다** | ε = t·θ/(2L). 얇은 힌지는 ε가 폭발한다. 456mm(38×12)의 판을 꼬리 38mm 안에 접어 넣는다 |
| **③ 정지 위치는 스프링이 아니라 하드 업스톱이 정의한다** | 크리프가 진행돼도 **힘만 변하고** 홀 센서 영점·자석 갭·딥은 불변 |

**참고 영상(dovetail, "I 3D Printed a Working Piano")과의 관계**: 컴플라이언트 메커니즘 + 모듈식 건반이라는 방향은 같다. 단 공개된 치수·STL이 없어(2026-09 확인) 아래 수치는 전부 직접 계산했다. 사진으로 보여주신 **print-in-place 나선 스프링은 계산 결과 채택하지 않았다** — 사유는 §2.4.

### 2.1 교차 판스프링 피벗 (cross-axis flexural pivot) — 회전 전담

| 항목 | 값 | 근거 |
|---|---|---|
| 구성 | 판 **4장**, +45° 2장 / −45° 2장을 **x 방향으로 교대 배치** | 같은 평면에서 교차시키면 서로 관통한다. 폭 방향으로 비켜 놓으면 닿지 않고 같은 운동학을 얻는다 |
| 판 치수 | **t_p = 0.84 (2벽×0.42) · L_p = 16.0 · b_p = 2.5 ×4 (유효폭 5.0)** | 4×2.5 + 3×0.6 = 11.8 < stem 12.108 ✔ |
| 교차점 | **(y, z) = (165, 18.3)** — 자석 바닥면과 같은 높이 | 이게 핵심. 회전중심을 자석면에 두면 자석의 수평 이동이 55(1−cosθ)=**0.118mm**로 최소가 된다 |
| 판 끝 좌표 | 고정단 z=12.64 (y=159.34 / 170.66) · 가동단 z=23.96 | ±L/2/√2 = ±5.657 |
| **회전 강성** | K_θ = 2E·b·t³/(12L) = **55.6 N·mm/rad** → 3.75°에서 3.64 N·mm = **앞끝 2.25 gf** | 복귀력의 4.5%만 차지 → 힘 곡선을 거의 오염시키지 않는다 |
| **변형률** | ε = t·θ/(2L) = **0.172%** · σ = 3.09 MPa | 예하중이 없어 **평균응력 0** → σ_a = 1.55 MPa, PETG 2×10⁶ 내구한도 4.5 MPa 대비 SF 2.9 |
| 수직 강성 | 2(E·b·t/L)cos²45° = **472 N/mm** → 연타 22N에서 처짐 **0.047mm**(딥의 0.4%) | 단일 판 피벗은 같은 조건에서 0.611mm — 자석 위치와 딥을 동시에 파괴한다 |
| 회전중심 이동 | L·θ²/16 = **0.0043mm** | 단일 캔틸레버 피벗 0.39mm 대비 90배 우수 |
| 측방(x)·요(yaw) | 판만으로는 부족 → **가이드 콤 3줄로 구속**(§2.5) | 교차 판은 좌우로 약하다. 이것이 v1.5의 핀/슬롯을 콤으로 대체해 유지하는 이유 |
| **고정단 결합** | 판 4장의 고정단을 **11.8 × 15 × 3.4 한 덩이 발**로 묶고, 키베드 포켓(12.1 × 15.6, z 9.2~12.2)에 **위에서 떨어뜨려 넣는다** | 도브테일 슬라이드는 stem 12.108 안에서 벽 두께가 남지 않는다. 드롭인 + 레일 압박이 더 단순하고 더 강하다 |
| **탈착** | 예하중 레일 M3 2개를 풀면 모듈 12키가 통째로 들리고, 1키만 빼서 교체할 수 있다 | 레일이 곧 리테이너다. 별도 체결부 0 |

### 2.2 사행 복귀 판스프링 (folded serpentine leaf) — 복귀력 전담

| 항목 | 값 |
|---|---|
| 구성 | 세그먼트 **12개 직렬**, 각 **ℓ = 38 (y 180~218) · t = 2.10 (5벽×0.42) · b = 11.5 등폭** |
| 접힘 간극 | **2.2 mm** (출력 상태) — 조건 g ≥ 2δ + 0.4 = 2.21, δ = x₀/n = 0.906 |
| 스택 높이 | 출력(자유) **49.4** (z 13.2~62.6) → 설치(예압) **39.4** (z 13.2~52.6), 노즈 포함 53.7 |
| 강성 | k_seg = E·b·t³/ℓ³ = 3.494 → 접힘부 손실 0.88 → **k = 0.2562 N/mm** |
| **유효 작용 반경** | **r = 34 mm** (= 판 중점 y=199 − 165) |
| 예압 | x₀ = **10.87 mm**, F_rest = **2.786 N**, 스트로크 s = 10.8×34/165 = **2.226 mm**, **예압비 p = 4.89** |
| 응력 | σ_rest = **6.26 MPa** · σ_bottom = **7.54 MPa** · **ε_bottom = 0.419%** |
| 피로 (Goodman) | σ_a = 0.64 · σ_m = 6.90 → 0.64/4.5 + 6.90/45 = 0.296 → **안전율 3.4** |
| 뿌리 | 판0은 y=218에서만 스파인에 붙는다(뿌리 기둥). 나머지 길이는 전부 자유 |
| 자유단 | 판11 앞끝(y=180)에 Ø2 노즈 → 예하중 레일과 **선접촉(bearing)**. 체결 없음 |

**왜 작용 반경이 34인가 (이 설계의 핵심 트레이드오프)**

힘 상승률과 크리프 응력은 같은 손잡이의 양 끝이다. 예압비 p = x₀/s에 대해

```
  앞끝 다운웨이트 상승분 Δ = τ_total /(165 × 0.0098 × p) = 58.6/p  [gf]
  상시 응력          σ_rest = 3·F·ℓ /(b·t²),  F = τ_total / r
  그리고   p = 0.0994 · n · ℓ³ /(r² · t³)      ← r 가 작을수록 평탄, 대신 σ 상승
```

r을 줄이면 힘은 평탄해지지만 응력이 오른다. **부피는 r과 무관**하다(V = W·E·p/(η·σ_rest²)). r = 34는 σ_rest를 크리프 허용선 6~7 MPa에 두면서 상승률을 최대한 낮춘 점이다. 피벗 앵커 레일이 y=174까지 차지하므로 판을 더 앞으로 당길 수 없다 — 이것이 r의 하한을 만든다.

### 2.3 힘 곡선 — 정직한 수치

| | 정지 | 바닥(딥 10.8) |
|---|---|---|
| 사행 판 | 58.6 gf | 70.3 gf |
| 건반 자중 (CoM 피벗 앞 78.2, 18g) | −8.6 | −8.6 |
| 교차 판 피벗 | 0 | +2.3 |
| **합계 앞끝 다운웨이트** | **50.0 gf** | **64.2 gf** |

**상승률 +28.5%.** v1.5의 사양은 "≤20%"였고 **이 구조로는 미달이다.** 조사 단계의 기본형(+50%)보다는 크게 나아졌지만 완전 평탄은 아니다. 감각적으로는 "그랜드 피아노"가 아니라 **좋은 러버돔 ~ 라이트 신스 액션**에 가깝다. 더 낮추는 수단은 셋뿐이고 전부 단계 0 T8 이후 결정이다.

1. **캠 앤빌** — 레일 접촉면을 곡면으로 깎아 스트로크 중 r을 34 → 26으로 줄이면 토크가 상수에 가까워진다. ±0.1mm 공차에 민감해 **실물 튜닝 전제**. 레일은 별도 부품이므로 캠 3종(R∞/60/40)을 인쇄해 갈아 끼우며 맞출 수 있다 — 건반 재출력 불필요.
2. **보타이 테이퍼** — 판 폭을 양끝 11.5 → 중앙 3.5로 줄이면 형상효율 η가 1/9 → 1/4로 올라 같은 강성에서 응력 −25%, 즉 r을 더 줄일 여유가 생긴다. **단 on-side 출력에서 21.8° 준수평 천장이 생겨 서포트가 필요하다.** 계단형(4mm 단차 2개)으로 바꾸면 4mm 브리지로 해결되므로 T8에서 A/B 비교할 것.
3. **세그먼트 추가** — n을 12 → 16으로 늘리면 +23%까지 내려가지만 스택이 39 → 49mm로 자란다.

### 2.4 채택하지 않은 것과 그 계산

| 방식 | 기각 사유 (계산) |
|---|---|
| **참고 사진의 print-in-place 나선 스프링** | PETG print-in-place 클리어런스 0.4mm/면 → 10.8mm 스트로크를 코일 압축으로 받으려면 **코일 27개**. 스프링 지수 C=D/d를 6~9로 두면 외경 8~11mm인데 **반음 피치 13.708에 간신히 1개**. 결정적으로 소선이 **비틀림**을 받아 FDM 최약 모드인 층간 전단을 직격한다. 총기 모형 스프링은 수백~수천 사이클용 간헐 부품이라 하중 이력이 근본적으로 다르다. **시각적 매력은 인정하지만 이 하중에서는 성립하지 않는다** |
| **얇은 힌지 (living hinge)** | ε = t·θ/(2L). t=0.5·L=2에서 스트로크만 **0.82%**, 예압 포함 **2.45%(σ 44 MPa)** → PETG 항복 초과. FDM 리빙힌지의 문서화된 수명은 **25 사이클**(SLS PA12도 30~50) — 요구 10⁶과 4~5 자릿수 차이. 사출 PP의 10⁶은 재료가 아니라 분자배향+냉간가공에서 나오므로 FDM 재현 불가 |
| 노치 / 원호 플렉셔 | 예압 포함 ε **3.27%**. 응력이 노치 바닥 한 점에 집중되는데 FDM 노치 바닥은 Z-심과 외벽 접합부가 겹치기 쉬워 균열 최적 시작점이 된다 |
| 단일 판 피벗 / LET 조인트 | off-axis 강성 부족. 22N에서 **0.611mm** 처짐 = 딥의 5.7% |
| 자석 반발 복귀 | 역거듭제곱 법칙. 힘 변동 ≤20% 조건이 갭 **g₀ ≥ 1.47r = 81mm**를 요구 — 키베드 내부 높이 18.3에 안 들어간다. 현 센싱 자석은 정지 갭에서 1.6 gf(필요 176 gf) |
| 꼬리 카운터웨이트 | 현 피벗에서 키당 **225 g** 필요. 피벗을 앞당기면 75g으로 되지만 중력 복귀시간이 **질량과 무관**하게 40ms(≈12Hz)로 고정 — 200bpm 16분음표 연타 13.3Hz를 못 맞춘다 |
| 좌굴 스트럿 | 키베드 수직 여유 12mm에서 ε **6.5%** |
| TPU 토션 슬리브 | 공학적으로는 가장 방어 가능한 대안이지만 **"단일 프린트" 목표와 충돌**. §9의 1순위 폴백으로 남긴다 |
| 예하중 0 설계 | 예압이 없으면 힘이 0 → 50gf로 변한다(상승률 ∞). **예하중은 선택이 아니라 강제 조건**이고, 그래서 크리프가 피로를 제치고 1순위 리스크가 된다 |

**흑건 딥은 7.47mm로 백건 10.8mm와 다르다.** 피벗을 공유하면 기하적으로 강제되는 결과이고, 밸런스 레일을 공유하는 어쿠스틱 피아노도 같은 성질을 갖는다(흑건 앞끝이 피벗에 더 가까우므로 딥이 얕다). **허용하기로 결정** — 88키가 단 2종(백/흑)으로 끝나고 키베드가 완전히 균일해진다. 허용하지 않으려면 흑건 피벗만 y=150으로 분리해야 하고 키베드가 2종으로 갈라진다.

### 2.6 레트오프(let-off) — v2.1로 연기

건반 밑면에 얕은 아치(h=0.42 · H=0.84 · L=16 · Q = H/h = 2.0)를 두면 딥의 75% 지점에서 **앞끝 환산 11 gf의 스냅 피크**가 생겨 그랜드의 이스케이프먼트 감각(10~15 gf)을 낸다. 문헌 판정 기준은 1.23 < Q < 2.31이 모노스테이블(항상 복귀)이고 **Q > 2.31은 바이스테이블 = 눌린 채 고착(기능 고장)** 이다. 다만 현 배치에서 아치를 넣을 y 구간이 다운스톱·PCB와 충돌해 리세스 설계가 필요하다. **v2.0 건반에는 넣지 않고, 단계 0 쿠폰 T7(Q = 1.5/1.8/2.0/2.2)로 먼저 검증한 뒤 v2.1에서 확정한다.**

### 2.7 출력 규칙 — on-side 자세가 모든 기하의 전제

건반을 **옆으로 세워(on-side)** 출력한다. 베드 접지면 = **218(길이) × 56.6(높이)**, 빌드 방향 = **건반 폭**(백건 앞블록 21.9 / stem 12.1).

| 규칙 | 근거 |
|---|---|
| **on-side 고정** | 이 자세에서만 ① 판의 굽힘응력이 **100% 층 평면 안**에 놓이고 ② 접힘 간극 11개가 빌드 방향으로 뻗은 **수직 슬롯**이 되어 **서포트가 0**이다. 눕혀 찍으면 굽힘이 층간 인장이 되어 수명이 약 절반으로 떨어지고 층간 박리로 갑자기 파단한다 |
| **스프링 두께는 압출 폭의 정수배** | 0.42 기준 — 사행 판 **2.10 (5벽)**, 피벗 판 **0.84 (2벽)**. 슬라이서에서 해당 영역이 **인필 0·전 perimeter**로 채워지는지 프리뷰로 확인. **k ∝ t³이라 0.05mm 오차 = 다운웨이트 ±7%** |
| 서포트 금지 구역 | 판 표면·피벗 판·노즈. 서포트 자국은 노치가 되어 피로 시작점이 된다. 등폭(b=11.5) 설계는 오버행이 0이므로 애초에 필요 없다 |
| Z-심 제어 | 판의 최대 인장면 반대쪽에 고정하거나 scarf joint seam. **랜덤 심 금지** — 심이 인장면에 떨어지면 거기서 파단한다 |
| 층 두께 | 판·피벗 구역 **0.16**, 본체 0.2 |
| 속도 | **25~35 mm/s**. 20 → 80 mm/s에서 피로수명 감소가 보고된다. 인필율·패턴은 피로에 유의미하지 않으므로 층두께·벽 수에 투자할 것 |
| 엘리펀트 풋 | 접지면은 **건반 옆면**이므로 첫 층 압착은 **폭**(측면 클리어런스 0.3/면)에 영향을 주고 **판 두께 t에는 영향이 없다**(t는 베드 평면 안). 보정 0.15 적용 |
| 브림 | 218 × 56.6 접지면은 길고 좁다. 스커트 대신 **브림 5mm**, 베드 80°C, 인클로저 불필요 |
| 모듈 단위 배치 통일 | 12키 모듈은 **같은 판·같은 배향·같은 베드 위치대**에서 출력. 판이 바뀌면 쿠폰 1개를 함께 뽑아 강성 드리프트를 기록 |
| 수축 보정 | 100mm 바 실측 → 슬라이서 스케일. 같은 재료·프린터·스케일 |

**판당 몇 개가 올라가는가** — 부품 하나가 218 × 56.6이므로 베드가 결정한다.

| 베드 | 배치 | 판당 건반 | 88키 |
|---|---|---|---|
| 220 × 220 | 218이 X에 안 들어감 → **45° 대각** ((218+57)/√2 = 194 ≤ 220 ✔) | 2 | 44판 |
| 250 × 210 | X 직배치, Y로 3줄 | 3 | 30판 |

> **미해결 — 보유 프린터 사양(노즐 지름·압출 폭·베드 크기·인클로저).** 판 두께 2.10 = 5벽이라는 결정이 전부 **압출 폭 0.42** 가정에 걸려 있다. 다른 값이면 SCAD 최상단 `ew` 하나만 고치면 전 기하가 따라오지만, **벽 수(5)는 다시 골라야 한다.**

### 2.8 88키 레벨링

정지 위치는 꼬리 업스톱(y 196~208)이 정의하고 오차는 앞끝에서 **4.5배**로 증폭된다. 키별 10×10 TPU 패드(연속 스트립 금지) + 펀칭 **0.05 · 0.1 · 0.2 · 0.5**로 맞춘다. 직선자로 앞끝 정렬, 인접 단차 ≤0.3. 88키 × 2회전 × 2분 ≈ 6h.

**다운웨이트 편차는 별도 문제다.** t의 ±0.05 오차가 ±7%를 만든다. 2단 조정: ① **예하중 레일 높이**(모듈 단위, M3 반 바퀴 = 0.25mm = **약 4.3 gf**) ② 레일 아래 **키별 0.2mm 심**. 조립 후 그램 게이지로 88키 실측 로그를 남길 것. 참고로 **트리거 포인트와 속도 커브는 홀 센서 아날로그값이 있으므로 펌웨어로 무료 보정되지만, 다운웨이트는 기계적으로만 잡힌다.**

```
     정지: 자석 멀리 (≈7mm) ── 출력 ≈ 널 −0.05V   ← rest = ADC 최댓값
     눌림: 자석 가까이 (≈3.5mm) ── 출력 ≈ 널 −0.28V ← 스윙 ≈285 LSB
     클램프 위험은 눌림 쪽. 공차 −0.54에서도 널 −0.40V 이내가 되도록 눌림 갭을 정함
```

### 3.1 로트별 눌림 갭 — 헤드룸 ±0.6V, 여유 0.2V, 공차 −0.54 포함

| 로트 (3.3V 감도) | **눌림 갭 (소자)** | 정지 갭 | 눌림 출력 | 스윙 LSB 공칭 / +0.54 / −0.54 | 심 (key_elev 12.1) |
|---|---|---|---|---|---|
| Honeywell 정품 (0.92 mV/G) | **3.4 mm** (표면 ≈2.7) | 7.0 mm | 널 −0.28 V | 284 / 197 / 423 | 심 2.7 mm |
| 클론 V2 (1.19 mV/G) | **3.7 mm** (표면 ≈3.0) | 7.3 mm | 널 −0.28 V | 285 / 203 / 414 | 심 2.4 mm |
| 클론 V3 (1.65 mV/G) | **4.2 mm** (표면 ≈3.5) | 7.8 mm | 널 −0.29 V | 285 / 208 / 402 | 심 1.9 mm |

- **갭(심) = 로트 감도 상한 기준**(가장 민감한 소자가 눌림 −0.40V 이내). **기본 스윙 상수 = 로트 감도 하한 기준.** 단계 0에서 100개 전수 감도 측정(≈1h) 후 ±10% 선별해 모듈별로 묶으면 산포 항 소멸.
- 스윙 ≈285 LSB는 세 로트 모두 같음(정의상). +0.54 공차에서 ≈200 → **그때 임계 간격 A–C ≈40 / C–B ≈50**(공칭 57/71). 클램프 기준은 **§8 게이트 ③(눌림 출력 ≥1.20V = 널 −0.45V)** 하나로 통일 — 재계산 V2/V3 −0.54에서 1.24V로 통과.
- 극성은 이득 없음(헤드룸 대칭) — 통일만.
- **선택안(스윙 3배)**: 센서 Vcc = VBUS 5V(10Ω + 100µF RC 후), 먹스는 **3.3V 유지**, 채널마다 10kΩ 직렬. 헤드룸 1.45V → 눌림 갭 ≈2.5, 스윙 ≈900 LSB. 단 VBUS 리플이 출력에 실림 — 단계 0에서 리플 p-p ≤20mV 확인, 아니면 폐기.

### 3.2 벨로시티 — 두 임계값 dt + 연타 경로

```
ADC (널에서 아래로)
 rest ──────╮ 10%  A  t1 기록
             ╲ 30% C  연타 재무장
              ╲ 55% B  t2 → dt → velocity, Note On   ← 이동 79%: 실제 피아노(80~90%)에 근접
 pressed ──────╰──
```

| 임계 | 스윙 | 이동 (Honeywell 기준, 타 로트 ±2%) |
|---|---|---|
| A | 10% | 1.0 mm (27%) |
| C | 30% | 2.1 mm (57%) |
| **B** | **55%** | **2.8 mm (79%)** |

| 항목 | 값 (잠정, **하드코딩 금지**) |
|---|---|
| A→B 자석 이동 | **1.85 mm** (C→B 0.76, 보정비 **2.4**) |
| dt | fff 앞끝 0.9 m/s(자석 0.3) → **6.2 ms**, ppp 0.015 → 369 ms, 0.01 → 554 ms |
| 타임아웃 | **700 ms** |
| 로그 1스텝 | ≈200 µs → 84µs 스캔 = 0.42 스텝 ✓ |
| 노트오프 | B 역통과 |
| 릴리즈 벨로시티 | B→A dt, A 도달 시에만 |
| 히스테리시스 | **실측 스윙의 8%** (공칭 23, +0.54에서 16 LSB) — 절대값이면 +0.54 공차에서 A–C 40을 넘음 |

```
IDLE → A하향(t1) → B하향(NoteOn, dt=t2−t1) → PRESSED
A하향 후 B 미도달 재상승 → IDLE (t1 폐기)
PRESSED → B상향(NoteOff) → PARTIAL
PARTIAL → A상향 → IDLE
PARTIAL → C상향 → REARMED
REARMED → A상향 → IDLE
REARMED → C하향(t1') → B하향(NoteOn, dt' × 2.4)
```

단계 1 게이트: 10Hz 연타 100회 무유령·무누락.

### 3.3 샘플링 예산

49E 전부 소싱 전용(싱크 65µA) → 풀다운 + 3~5µs 대기. 채널 7µs → 12키 **84µs (12kHz)** → fff 1스텝 대비 0.42 스텝 ✓. SDK `adc_read()` 직접 호출. 노이즈 대책 주력: 3V3 벌크 10~47µF + 출력 1nF + 단계 0 실측. `GPIO23=HIGH`는 Pico/Pico 2만(W는 WL_GPIO1, 클론 LDO 보드 해당 없음).

**게이트 ④ 합격선: 유휴 p-p ≤ 스윙/10 ≈ 25 LSB.** 미달 시 1nF → 2탭 평균(168µs, fff 0.8스텝) → 정품 Pico 순.

| 항목 | **v1.3** |

## 6. Raspberry Pi 5

### 6.1 OS: Lite + SDL kmsdrm

Desktop은 PipeWire가 HAT을 선점(`Device busy`). **OS Lite**, 게임은 `apt install python3-pygame`(시스템 SDL2, KMSDRM 포함) + `video·render·input` 그룹. **게임 오디오는 반주를 MIDI로 fluidsynth에 보내 같은 신스로 재생**(HAT `hw:` 배타 유지, 믹서 불필요, 같은 클록) — 또는 HDMI 오디오 분리. 단계 2 게이트: Pico 포트 fluidsynth 1회 구독.

### 6.2 지연 — 오디오 버퍼 기준 (키→소리 +2~3ms, RTPRIO 전제)

| 출력 | FluidSynth | Pianoteq | 오버레이 / CARD |
|---|---|---|---|
| USB 동글 | 10~12 ms | 10~12 ms | — |
| **HiFiBerry DAC+ Zero** (3.5~4만) | **4~6** | 3~4 | `hifiberry-dac` / `sndrpihifiberry` |
| Raspberry Pi DAC+ (4~4.5만) | 4~6 | 3~4 | `iqaudio-dacplus` / `IQaudIODAC` |
| Pisound (15~18만) | 3~4 | 1.5 | Pianoberry |

`dtparam=audio=off`.

### 6.3 엔진·유닛

FluidSynth 2.0+ (Bookworm 2.3.1 / Trixie 2.4.4), FluidR3 시작. Pianoteq +22만 선택.

```ini
[Unit]
After=sound.target
StartLimitIntervalSec=60
StartLimitBurst=10
[Service]
ExecStart=/usr/bin/fluidsynth -is -a alsa -o audio.alsa.device=hw:CARD=sndrpihifiberry -r 48000 -z 64 -c 3 -o midi.autoconnect=1 -o synth.dynamic-sample-loading=1 /usr/share/sounds/sf2/FluidR3_GM.sf2
LimitRTPRIO=95
LimitMEMLOCK=infinity
Restart=on-failure
RestartSec=2
[Install]
WantedBy=multi-user.target
```

`-is` 없으면 systemd 아래서 셸이 EOF를 읽고 **exit 0으로 조용히 종료**(Restart=on-failure 무반응). `-s`는 TCP 9800(가정 LAN 허용). `midi.autoconnect=1`이 핫플러그·재열거 자동 연결(v2.0.0, fluid_alsa.c). 리듬게임은 ALSA seq.

### 6.4 USB 전원

모듈당 VBUS **79~116mA**(센서 12×4~7mA @3.3V + Pico 30 → ÷0.85 ÷5V), 8모듈 **0.63~0.93A**. Pi 5 USB 600mA(PD 5A 협상 시 1.6A 자동). → **셀프파워 허브(≥2A)가 1차 해법**, 27W PSU는 Pi 자체 요건. HAT은 USB 무관.

**역급전 검사**: Pi에 연결하기 **전** 허브 업스트림 A 플러그 핀1–핀4를 테스터로 측정, 허브 ON에서 **>0.5V면 역급전**(LED 소등은 증거 아님). 연결 후 40핀 헤더 5V 측정. 역급전 시 다른 허브 / VBUS 단선 케이블 / 공식 Pi USB3 허브 ×2. 전원 순서 Pi 먼저.

## 10. 결정 / 열린 것

**결정**: 모노리식 단일 프린트 · PETG(PLA 배제) · 교차 판스프링 피벗 · 12단 사행 복귀 판 · 드롭인 앵커 + 예하중 레일 리테이너 · on-side 출력 · 정지 위치 = 꼬리 업스톱 · **흑건 딥 7.47 허용** · **힘 상승 +28.5% 수용(T8에서 +20~23% 목표)** · 목표 수명 10⁶ 사이클 + **12키 모듈을 소모품으로 선언**(재출력 필라멘트 약 ₩8,000) · 레트오프 아치는 v2.1 · 홀 센서/Pico/Pi 5/FluidSynth는 v1.5 그대로.

**열린 것**:
1. **보유 프린터 사양** — 노즐·압출 폭·베드. `ew = 0.42` 가정이 판 두께 2.10(5벽)을 낳았다. **1순위 미해결**
2. **PETG 브랜드/색상** — 88키분을 한 배치로 확보한 뒤 그 배치로 쿠폰을 뽑을 것
3. 캠 앤빌을 v2.1에 넣을지 — T8 실측 후
4. 계단형 보타이 테이퍼 — T8 A/B
5. 꼬리 보조 추 10~30g — 손끝 등가 관성이 현 설계 약 5g vs 실제 그랜드 25~30g. 넣으면 피아노에 가까워지지만 100% 모노리식은 깨진다(추는 비운동 부품이라 허용 가능하다는 판단도 가능)
6. 건반 셸의 실제 질량·CoM — 계산에 18g·78.2mm를 썼다. 셸 인필 확정 후 τ_keyweight가 바뀌면 x₀를 재계산할 것
7. 센서 3.3V vs 5V / Ø3 vs Ø4 자석 — 단계 0 실측 후
8. Pianoteq · 리듬게임 판정 기준 · 캘리브레이션 저장
